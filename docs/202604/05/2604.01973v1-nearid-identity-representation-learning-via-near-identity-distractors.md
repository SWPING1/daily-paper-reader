## 摘要
在评估个性化生成和图像编辑等聚焦于身份的任务时，现有的视觉编码器往往将物体身份与背景上下文纠缠在一起，导致表示和度量指标不可靠。我们引入了首个规范化框架，通过使用近身份（NearID）干扰项来解决这一缺陷。在该框架中，语义相似但不同的实例被放置在与参考图像完全相同的背景上，从而消除了上下文捷径，并将身份隔离为唯一的判别信号。基于这一原则，我们提出了 NearID 数据集（包含 1.9 万个身份和 31.6 万个背景匹配的干扰项）以及一套严格的基于边际（margin-based）的评估协议。在此设置下，预训练编码器的表现较差，其样本成功率（SSR，一种严格的基于边际的身份判别指标）低至 30.7%，且经常将干扰项的排名置于真实的跨视图匹配之上。为了解决这个问题，我们在冻结的主干网络上学习身份感知表示，采用两层对比目标来强制执行以下层级关系：相同身份 > 近身份干扰项 > 随机负样本。该方法将 SSR 提高到 99.2%，使局部级判别力提升了 28.0%，并在 DreamBench++（一个与人类对齐的个性化基准测试）上实现了与人类判断更强的一致性。

## Abstract
When evaluating identity-focused tasks such as personalized generation and image editing, existing vision encoders entangle object identity with background context, leading to unreliable representations and metrics. We introduce the first principled framework to address this vulnerability using Near-identity (NearID) distractors, where semantically similar but distinct instances are placed on the exact same background as a reference image, eliminating contextual shortcuts and isolating identity as the sole discriminative signal. Based on this principle, we present the NearID dataset (19K identities, 316K matched-context distractors) together with a strict margin-based evaluation protocol. Under this setting, pre-trained encoders perform poorly, achieving Sample Success Rates (SSR), a strict margin-based identity discrimination metric, as low as 30.7% and often ranking distractors above true cross-view matches. We address this by learning identity-aware representations on a frozen backbone using a two-tier contrastive objective enforcing the hierarchy: same identity > NearID distractor > random negative. This improves SSR to 99.2%, enhances part-level discrimination by 28.0%, and yields stronger alignment with human judgments on DreamBench++, a human-aligned benchmark for personalization.
