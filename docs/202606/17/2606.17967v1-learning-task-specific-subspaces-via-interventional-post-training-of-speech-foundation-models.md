## 摘要
语音基础模型在大量无标签语音数据上预训练，产生适用于多种任务的通用表示。然而，这些表示以分布式方式编码了关于显著语音变量的信息，而下游语音任务仅依赖于其中一部分变异性。本文提出了一种利用干预式对比学习的后训练微调方法。通过利用干预式数据集和多部分对比损失，我们学习从语音基础模型的纠缠表示空间到分离的内容和说话者子空间的变换。我们在说话者验证和关键词检测任务上评估所学表示，展示了改进的域外说话者验证性能，以及说话者和内容信息在学习子空间中被分离的证据。

## Abstract
Speech foundation models, pre-trained on large corpora of unlabelled speech data, produce general-purpose representations which are useful across tasks. However, these representations encode information about salient speech variables in a distributed manner, while downstream speech tasks rely on only some of this variability. In this work, we propose a post-training refinement approach using interventional contrastive learning. By leveraging an interventional dataset and multi-part contrastive loss, we learn a transformation from the entangled representation space of speech foundation models into separate content and speaker subspaces. We evaluate the learnt representations on speaker verification and keyword spotting tasks, showing improved out-of-domain speaker verification performance and evidence that speaker and content information are separated across the learned subspaces.

# 基于干预式后训练的语音基础模型任务特定子空间学习：详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：现代语音基础模型（如 wav2vec 2.0、HuBERT、WavLM）通过自监督学习在大规模无标签数据上训练，生成通用语音表示。然而，这些表示**高度纠缠**地编码了说话人身份、语言内容、环境噪声等多种语音变量。下游任务（如说话人验证、关键词检测）往往只依赖于其中一部分变异性，而无关变量（如说话人对于内容任务）会干扰性能。
- **背景**：现有解耦方法依赖独立性假设（如非线性ICA），但该假设难以保证真正解耦，且对随机种子和架构敏感。近期图像领域转向**因果解耦**，利用基于干预的数据提供解耦保证。本文将这一思路引入语音领域。
- **整体含义**：提出一种**后训练微调**方法，通过干预式对比学习，将预训练模型的纠缠表示映射到分离的内容子空间和说话人子空间，从而提升下游任务在匹配子空间上的表现，并证明信息被成功分离。

## 2. 方法论

### 核心思想
- 利用**干预数据集**（包含对因果变量——内容和说话人——进行干预的样本对）训练一个轻量级的子空间映射网络，将预训练模型池化后的单一表示变换为多个子空间表示。
- 通过**多部分对比损失**（multi-part contrastive loss）联合优化每个子空间内的相似性，并加入**正交性正则化**以惩罚子空间之间的信息重叠。

### 关键技术细节
1. **架构**（图2）：  
   - 输入语音 `x` → 冻结的预训练语音基础模型（backbone） → 均值池化 → 子空间映射网络（3层MLP，无瓶颈，所有层维度均为768） → 输出维度768，等分为内容子空间 `z_c`（384维）和说话人子空间 `z_s`（384维）。
2. **干预对比损失**：  
   - 对于每个子空间 `j`，定义对比分布 `q_{i,j}`：
     ```
     q_{i,j} = exp(a·b_i/τ) / Σ exp(a·b_k/τ)
     ```
     其中 `a` 为锚点样本的子空间嵌入，`b_k` 为批次中其他样本的子空间嵌入，`τ` 为温度超参数。
   - 真实分布 `p_{i,j}` 由干预标签 `M_j` 决定：若两个样本在该子空间对应的因果变量相同（如相同说话人），则为正样本。
   - 损失为交叉熵：`L_con^j = - Σ p_{i,j} log q_{i,j}`。
3. **正交性正则化**：  
   - 对于批次嵌入矩阵 `Z`，子空间 `j` 和 `k` 之间的正交损失为：`L_orth^{j,k} = || Z_j^T Z_k ||_F^2`。该损失强制不同子空间的输出向量相互正交。
4. **总损失**：  
   ```
   L = λ_con Σ_j L_con^j + λ_orth Σ_j Σ_{k>j} L_orth^{j,k}
   ```
   本文中 λ_con = λ_orth = 1（未明确说明，但实现中应为等权重）。

### 干预数据集构造
- 使用零样本TTS系统（F5-TTS）合成语音：  
  - 从LibriTTS test-clean选取32个说话人作为训练集，6个说话人作为开发集。  
  - 每个说话人选取256条参考音频（3-10秒），配合256条目标文本（也来自LibriTTS）。  
  - 穷举组合：每个说话人用所有目标文本合成语音，共8192条训练集，1536条开发集。  
  - 每个批次构造为**说话人×内容矩阵的子块**（如图1），确保批次内包含密集的干预对（相同/不同说话人、相同/不同文本组合）。

## 3. 实验设计

### 数据集
- **训练/开发**：自建合成数据集（见上）。
- **下游评估**：
  - 说话人验证（SV）：**VoxCeleb1** test set（域外评估，因为训练数据为干净朗读语音，测试为真实对话语音）。度量：等错误率（EER）。
  - 关键词检测（KS）：**Speech Commands**数据集（12类），按照SUPERB协议训练线性分类器。度量：准确率（Accuracy）。

### Benchmark与对比方法
- **Backbone**：3种流行SSL模型（均从SUPERB实现获取，使用最后一层768维特征）：
  - wav2vec 2.0 Base
  - HuBERT Base
  - WavLM Base
- **基线**：
  - **None**：直接使用均值池化后的backbone表示（无子空间网络）。
  - **Content only**：只学习内容子空间（384维），无正交项。
  - **Speaker only**：只学习说话人子空间（384维），无正交项。
  - **Full**：联合学习两个子空间（384+384维），包含正交项。

### 实验设置
- 优化器：AdamW，训练50 epochs。单周期学习率策略（cosine annealing），最大学习率1e-4。
- 批大小：训练512，开发768（含所有6个说话人）。
- 每个实验运行5个随机种子，报告均值和标准误。

## 6. 主要结论与发现

1. **说话人子空间显著提升域外SV性能**：  
   - 对于所有backbone，Full模型和Speaker only模型得到的说话人子空间在VoxCeleb1上的EER低于直接使用backbone表示的基线。最好结果：WavLM Speaker only EER=24.6%，Full 24.7%，均低于文献报道的非专家人类水平（26.51%）。
2. **内容子空间表现不如基线**：  
   - Full模型的内容子空间在KS上准确率低于backbone直接池化结果（例如WavLM：93.0% vs 96.9%）。作者归因于对比学习任务（句子级匹配）与KS任务（词级）的不匹配。
3. **子空间存在信息分离**：  
   - 对于SV，匹配子空间（说话人）的EER远低于不匹配子空间（内容）。对于KS，分离证据较弱（不匹配子空间准确率也较高），暗示信息泄露或任务本身对内容需求不严。
4. **联合学习 vs 单独学习**：  
   - 没有显著证据表明联合学习两个子空间优于单独学习一个子空间。Full模型与Speaker only或Content only在各自任务上表现接近，但Full模型总参数更少（联合网络共享隐藏层，效率更高）。

## 7. 优点

- **方法创新**：将因果干预思想引入语音表示解耦，提出专门的多部分对比损失+正交正则化，不同于以往的单空间对比学习。
- **数据效率高**：仅用32个说话人、合成数据，就能在域外SV上取得超过非专家人类的性能，表明方法具有较强的泛化能力。
- **轻量化后训练**：基础模型冻结，仅训练一个3层MLP（约180万参数），训练时间短（<2h单卡），便于部署到现有系统。
- **实验设计严谨**：多随机种子、标准误报告、匹配/不匹配交叉验证，提供了清晰的信息分离证据。
- **可解释性**：子空间与因果变量一一对应，可直观解释模型行为。

## 8. 不足与局限

- **数据依赖性**：完全依赖合成TTS数据，可能引入TTS系统本身的偏差（如声学特征、韵律不自然），且无法保证和真实干预数据等价。
- **评估覆盖有限**：
  - 仅评估两个任务（SV和KS），未验证ASR、情感识别等任务。
  - 域外SV的绝对EER仍较高（~25%），距离最佳 supervised 模型（~5%）差距大，说明解耦能力有限。
  - 未在真实干预数据（如电话录音中同一说话人不同内容、同一内容不同说话人）上测试泛化。
- **内容子空间效果不佳**：可能是任务粒度不匹配，但未尝试调整损失函数或引入词级监督。
- **联合学习无增益**：表明正交正则化可能不足以有效减少信息泄漏，或者两个子空间共享网络参数导致容量竞争。
- **实验规模较小**：64条×32说话人=2048句训练，与现代SSL预训练几十万小时数据形成对比，可能不足以学习稳健映射。
- **未讨论不同池化策略**：仅使用均值池化，未探索自注意池化或加权池化可能带来的影响。
