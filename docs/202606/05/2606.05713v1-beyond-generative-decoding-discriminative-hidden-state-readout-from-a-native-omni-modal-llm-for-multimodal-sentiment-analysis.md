## 摘要
多模态情感分析（MSA）从语言、声学和视觉信号中推断人类情感。近期方法越来越多地通过生成式读取来适配大型多模态模型（LMM）：提示模型将情感分数作为文本字符串输出。虽然便捷，但这将连续回归与离散自回归解码绑定，带来了未测量的成本。我们重新审视这种读取机制，提出了一种基于原生全模态大语言模型（Qwen2.5-Omni-7B）的Thinker模块构建的判别式公式。我们不是进行文本解码，而是通过轻量级回归头在单次前向传播中映射最后一个非填充令牌的最终层隐藏状态到连续分数。使用4比特量化与低秩适应（QLoRA），整个7B管道（包括视频和音频处理）在单个消费级GPU（RTX 5090, 32 GB）上训练，峰值内存10-21 GB，可训练参数占比1.14%。通过固定骨干网络、数据和LoRA配置的受控比较，我们隔离了读取的影响。在CMU-MOSI和CMU-MOSEI上，我们的判别式读取无需特定任务特征工程即可达到最先进精度（MOSI：MAE 0.551, Corr 0.888；MOSEI：MAE 0.506, Corr 0.790），并表现出强多种子稳定性。相比之下，生成式读取即使经过等效监督训练，平均绝对误差也翻倍以上，产生不可解析或超出范围的输出（零样本2.8%），且延迟更高。模态消融实验揭示了CMU-MOSI上的文本主导模式。我们的发现表明，LMM的读取方式与其训练方式同等重要，证明判别式读取为连续MSA提供了更准确、高效且可靠的替代方案。

## Abstract
Multimodal sentiment analysis (MSA) infers human affect from language, acoustic, and visual signals. Recent methods increasingly adapt large multimodal models (LMMs) via generative readout: prompting the model to emit a sentiment score as a text string. While convenient, this ties continuous regression to discrete autoregressive decoding, incurring unmeasured costs. We revisit this readout mechanism and propose a discriminative formulation built on the Thinker module of a native omni-modal LLM (Qwen2.5-Omni-7B). Instead of text decoding, we map the final-layer hidden state of the last non-padding token to a continuous score via a lightweight regression head in a single forward pass. Using 4-bit quantization and low-rank adaptation (QLoRA), the entire 7B pipeline -- including video and audio processing -- trains on a single consumer GPU (RTX 5090, 32 GB) with 10-21 GB peak memory and 1.14% trainable parameters. Through a controlled comparison fixing the backbone, data, and LoRA configuration, we isolate the impact of the readout. On CMU-MOSI and CMU-MOSEI, our discriminative readout reaches state-of-the-art accuracy without task-specific feature engineering (MOSI: MAE 0.551, Corr 0.888; MOSEI: MAE 0.506, Corr 0.790) and exhibits strong multi-seed stability. In contrast, the generative readout -- even after equivalent supervised training -- more than doubles the mean absolute error, yields unparsable or out-of-range outputs (2.8% zero-shot), and suffers from higher latency. Modality ablations reveal a text-dominant regime on CMU-MOSI. Our findings indicate that how an LMM is read out is as consequential as how it is trained, demonstrating that a discriminative readout offers a more accurate, efficient, and reliable alternative for continuous MSA.

## 1. 核心问题与整体含义（研究动机和背景）

多模态情感分析（MSA）旨在从语言、声学和视觉信号中推断人类情感，通常输出一个连续的情感强度分数（如[-3, +3]）。近年来，基于大语言模型（LLM）和大多模态模型（LMM）的方法逐渐兴起，其主流做法是采用**生成式读取**（Generative Readout）：将情感分数作为文本字符串生成（如“1.5”），再解析为数字。虽然这种范式易于实现且与LLM原生接口兼容，但将连续回归任务与离散的自回归解码绑定，会引入精度限制、高延迟和输出不可解析等问题。然而，这些代价在现有文献中很少被量化。本文的核心问题是：**对于连续MSA任务，读取机制（Readout）的选择是否对性能有重大影响？** 作者认为生成式读取并非最优，并系统性地提出并验证了判别式读取（Discriminative Readout）的优势。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：放弃传统的生成式文本解码，而是从预训练全模态大模型的隐藏状态中直接回归连续情感分数。
- **骨干网络**：采用Qwen2.5-Omni-7B的Thinker模块（原生全模态模型，统一处理文本、图像、音频、视频），并去除其Talker（语音生成）头。
- **判别式读取**：
  - 对每个样本，将文本、视频帧（最多16帧）和（可选）音频输入Thinker，得到最后一层的隐藏状态序列H = [h1,...,hT]。
  - 取最后一个非填充令牌（non-padding token）的隐藏状态作为汇聚表示z = hℓ。
  - 通过一个轻量级MLP回归头（Linear 3584→256 + LayerNorm + ReLU + Dropout + Linear 256→1）预测连续分数ŷ = gϕ(z)。
  - 使用L1损失（MAE）优化，并对标签进行标准化（减去均值除以标准差）以防止模型塌缩。
- **生成式读取对比基准**：
  - 共享相同骨干和LoRA适配，仅改变读取方式：将标签渲染为数字字符串，采用语言建模交叉熵损失优化（提示模型生成字符串），推理时贪心解码并解析数字；记录不可解析率和超出范围率。
- **参数高效微调**：
  - 使用QLoRA：将骨干网络4比特NF4量化，冻结权重；在注意力层和前馈层注入低秩适配矩阵（rank=32, α=32, dropout=0.1）。
  - 仅训练LoRA矩阵和回归头，约103M参数（占总参数量1.14%）。
  - 启用梯度检查点和动态帧采样（均匀采样16帧，限制每帧像素预算），使得整个7B模型可在单张32GB消费级GPU（RTX 5090）上运行，峰值内存10-21GB。
- **训练超参数**：AdamW优化器，分层学习率（LoRA: 2e-4，头: 1e-3），余弦退火，梯度裁剪，梯度累积（有效批大小大于1）。

## 6. 主要结论与发现

1. **判别式读取显著优于生成式读取**：在受控对比下，判别式读取的MAE不到生成式的一半（MOSI: 0.667 vs 1.443），相关系数几乎翻倍（0.824 vs 0.491）。生成式读取会产生2.8%的不可解析输出和少量超出范围输出，而判别式读取零失败率。
2. **生成式读取即使经过有监督训练也无法缩小差距**：其相关系数反而下降（0.491→0.197），说明语言建模损失不适配连续回归（token级格式主导）。
3. **达到SOTA精度**：在全模态判别式配置下，在CMU-MOSI（MAE 0.551, Corr 0.888）和CMU-MOSEI（MAE 0.506, Corr 0.790）上匹配或超过近期专门设计的MSA系统，且无需手工特征工程。
4. **模态贡献分析**：在CMU-MOSI上文本模态占主导，加入视频和音频后回归指标轻微下降，但分类精度略有提升（文本+视频最佳）。这反映出该数据集的语言信息已足够丰富，多模态补充有限。
5. **硬件可行性**：整个7B管道可在单张消费级GPU上训练，降低了全模态LLM用于MSA的门槛。

## 7. 优点

- **设计新颖**：明确将读取机制作为MSA中独立的设计维度，并首次在严格控制条件下量化生成式读取的代价。
- **实用性强**：采用QLoRA和动态帧采样，使7B模型可在单张32GB GPU上运行，具备很好的可复现性和部署潜力。
- **实验严谨**：通过固定骨干和LoRA配置进行受控对比，分离了读取方式的影响；进行多种子稳定性检查；提供了表示空间分析支持结论。
- **诚实分析**：坦率讨论模态消融中的文本主导现象，不过度鼓吹多模态增益；明确列出局限性。
- **输出可靠性**：判别式输出始终合法且连续，避免了生成式的不稳定问题。
