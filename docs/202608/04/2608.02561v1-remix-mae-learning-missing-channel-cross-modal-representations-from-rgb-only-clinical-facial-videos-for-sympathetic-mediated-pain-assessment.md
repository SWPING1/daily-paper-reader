## 摘要
真实临床环境中的自动化疼痛评估受到临床面部视频数据稀缺（常仅有序列级自我报告标签）以及疼痛线索在RGB中可能微妙或接近中性的限制，而热成像和深度信号信息丰富却难以常规部署。为应对这些挑战，我们提出ReMiX-MAE（重建缺失通道跨模态掩码自编码器），一种自监督多模态掩码预训练框架，可从同步的RGB、热成像和深度视频中学习可迁移的面部表征，并显式训练对缺失模态的鲁棒性，从而支持仅RGB部署。为填补具有视频级自我报告和纵向治疗轨迹的临床面部疼痛数据空白，我们收集了交感神经介导疼痛（SMP）数据集，包含多次就诊的配对前后记录。在仅RGB部署下，我们使用直接特征提取和从RGB解码的伪多模态特征来评估ReMiX-MAE。在SMP上，ReMiX-MAE持续优于仅RGB掩码自编码器基线，而伪多模态特征在具有挑战性的五类设置中提供额外增益。在外部数据集上，ReMiX-MAE进一步显示出比仅RGB基线更鲁棒和标签高效的迁移性，凸显了其在数据受限临床场景中的优势。

## Abstract
Automated pain assessment in real clinics is limited by scarce clinically grounded facial video data with weak labels (often sequence-level self-report) and by the fact that pain cues can be subtle or near-neutral in RGB, while thermal and depth signals are informative yet impractical to deploy routinely. To address these challenges, we propose ReMiX-MAE (Reconstructing Missing Channel Cross-Modal Masked Autoencoder), a self-supervised multimodal masked pretraining framework that learns transferable facial representations from synchronized RGB, thermal, and depth videos and explicitly trains robustness to missing modalities, enabling RGB-only deployment. To fill the gap of clinically grounded facial pain data with video-level self-report and longitudinal treatment trajectories, we collect the Sympathetic Mediated Pain (SMP) dataset with paired pre- and post-recordings across multiple visits. Under RGB-only deployment, we evaluate ReMiX-MAE using both direct feature extraction and pseudo-multimodal features decoded from RGB. ReMiX-MAE consistently outperforms an RGB-only masked autoencoder baseline on SMP, with pseudo-multimodal features providing additional gains in the challenging five-class setting. Across external datasets, ReMiX-MAE further shows more robust and label-efficient transfer than RGB-only baselines, highlighting its advantage in data-limited clinical settings.

## 2. 论文提出的方法论

**核心思想**

ReMiX-MAE（Reconstructing Missing-Channel Cross-Modal Masked Autoencoder）是一个自监督多模态掩码预训练框架。它在 BP4D+（提供同步 RGB/热/深度面部视频的大规模多模态数据集）上进行无监督预训练，学习面部表征之后冻结编码器，仅在下游任务中训练轻量分类头，从而在数据极少的临床数据集上实现高效迁移。

**关键设计（三大核心技术）**

1. **Patch-wise 5-to-3 通道路由（RouteMix）**
   - 将 5 个原子通道 {R, G, B, Depth, Thermal} 按空间 patch 粒度采样 3 个通道，填入 3 通道输入张量中，保持与标准 3 通道视频骨干网络兼容。
   - 每个空间 patch 的路由三元组在时间上保持一致（保证时序一致性）；路由顺序由确定性优先级规则决定：`Depth ≻ Thermal ≻ R ≻ G ≻ B`。
   - 作用：在不改变输入通道数的前提下，让编码器在训练时能接触各种模态组合（如 RGB+Depth、RGB+Thermal、Depth+Thermal），实现早期融合。

2. **模态身份注入（Modality-Identity Injection, IdEmb）**
   - 由于混合通道 token 的来源不同，需要显式告知编码器每个 token 由哪些原子模态构成。
   - 每个原子模态分配一个可学习嵌入向量，通过 DeepSets 风格 MLP 聚合 token 内三个槽位的身份信息，生成 token 级偏置向量，加到编码器输入嵌入上（与 patch embedding 和位置编码相加）。
   - 作用：消除混合通道 token 的歧义，帮助编码器理解跨模态组合的语义。

3. **基于 Episode 的缺失模态模拟（Episode-based Missing-Modality Simulation）**
   - 预训练中定义 4 种 episode 类型，以固定概率采样：`mae`（标准掩码自编码，p=0.40）、`rgb_only`（仅 RGB 路由，p=0.40）、`cross_modal`（固定 RGB/辅助通道三元组组合，p=0.15）、`channel_drop`（模拟传感器故障，声明缺失模态，p=0.05）。
   - 关键区分：**MAE 掩码 M 与声明缺失集合 D 相互独立**——M 控制哪些 token 对编码器可见；D 控制哪些模态被视为逻辑缺失（用于辅助重建损失），且 D 不改变编码器的 token 可见性。这使得编码器能观察到“可见 token 中包含缺失模态占位符”的情况，增强对模态塌缩/传感器缺失的鲁棒性。
   - 作用：让模型学会在 RGB-only 部署时仍能通过跨模态关联补充缺失信息。

**预训练目标（损失函数）**

- **RGB 重建**：基于掩码 token 的 MSE 损失（patch 级像素回归）。
- **热成像重建**：Charbonnier 损失 + 异方差高斯负对数似然（NLL）损失（预测均值和对数方差）。
- **深度重建**：尺度不变损失（scale-invariant loss）+ NLL 损失。
- **辅助损失**：`L_cdrop`（在声明缺失集合 D 上计算与上述形式相同的重建损失）、`L_temp`（时间平滑性正则，在初始 RGB warmup 阶段后启用）、`L_frame`（SSIM 等帧级正则项）。
- **总损失**：`L_total = L_recon(M) + λ_cd · L_cdrop(D) + λ_temp · L_temp + λ_frame · L_frame`。

**推理阶段的两种 RGB-only 模式**

- **ReMiX-RGB**：直接冻结编码器，路由限制为 RGB 通道，提取特征。
- **ReMiX-Pseudo**：先用预训练的解码器从 RGB 重建出“伪热成像”和“伪深度”，再将原始 RGB 与伪模态按 RouteMix 混合输入编码器提取特征，相当于在推理时也享受多模态融合的好处。

**下游学习**：每个视频切分为 5 秒片段；片段内多时间窗口提取特征后，通过注意力 MIL（Multiple Instance Learning）模块聚合，训练轻量分类器；采用留一受试者交叉验证（LOSO）；训练时应用面部交换（face-swap）数据增强（比例为 0.75），且测试对象身份绝不参与增强，防止身份泄漏。

## 6. 论文的主要结论与发现

1. **ReMiX-MAE 在 SMP 上持续优于 RGB-only MAE 基线**：在 K=3/4/5 三种粒度下，Ours(RGB) 的 subject-level Accuracy 和 Macro-F1 均高于 MARLIN-RGB；例如 K=5 时 Accuracy 从 0.190 提升至 0.237。
2. **Pseudo 多模态特征提供额外增益**：ReMiX-Pseudo 在更细粒度（K=4/5）的困难设置中优于 ReMiX-RGB（K=5 时 Accuracy 达 0.255、Macro-F1 达 0.110），说明从 RGB 重建伪热/深度信号后再融合确实有帮助。
3. **跨数据库迁移更鲁棒**：在 SMP→UNBC 的 source-only 迁移中，Ours(RGB) 获得最高 Accuracy（0.280），Ours(Pseudo) 获得最高 Macro-F1（0.146），均优于 AU 和 MARLIN 基线。
4. **标签效率更高**：在 BioVid 上仅用 25%/50% 数据时，Ours(Pseudo) 一致优于有监督 TNT 基线，支持自监督预训练在数据受限临床场景的有效性。
5. **消融实验验证了关键设计有效性**：去掉 IdEmb 或 Episode 均导致性能下降，说明模态身份注入和缺失模态模拟都贡献了模型鲁棒性。
6. **纵向治疗追踪初步可行**：在配对 pre/post 的疼痛缓解检测任务上，ReMiX 的准确率和 F1（0.667/0.625）显著高于 MARLIN（0.500/0.400）。

- **方法论创新性强**：patch-wise 5-to-3 通道路由在固定 3 通道接口下实现了多模态早期融合，巧妙解决了“多模态训练、单模态部署”的接口兼容问题；将 MAE 掩码 M 与声明缺失 D 解耦是一个精妙的设计——编码器能看到“可见 token 含缺失模态占位符”，真正学到了模态缺失下的鲁棒推理。

- **实验严谨性**：LOSO 协议、外部身份 face-swap 增强（防止身份泄漏）、受试者级配对差异分析等都体现了良好的实验素养，结果统计的可信度较高。
- **部署实用性**：最终模型只需要 RGB 摄像头即可运行，对临床工作流程零侵入，实用转化潜力大。

## 8. 不足与局限

- **数据规模与多样性**：SMP 仅为单中心、36 名患者的小规模队列；作者也承认需要更广泛的人口覆盖和必要的多中心验证才能支撑更强的泛化性声明。
- **绝对性能有限**：即使 ReMiX-MAE 相对基线有提升，5 类分类的 Accuracy 仍在 0.25 左右（随机水平约 0.20），距离实际临床可用仍有相当距离；论文未进行正式假设检验，统计显著性存疑。
- **实验协议范围偏窄**：核心实验基本局限于冻结特征 + 轻量分类头的协议，未与端到端微调、更强时序模型（如 VideoMAE 微调、时域 Transformer 微调）进行完整对比；TNT 在 SMP 上的退化主要作为诊断证据，而非公平比较。
- **预训练数据与临床数据的域差异**：BP4D+ 是实验室受控条件下的情绪数据集（非疼痛相关），与临床真实环境（自然光照、随意姿态、自发行为）存在分布差异，可能限制预训练表征在 SMP 上的迁移上限。
- **PSPI 与 NRS 的不一致处理**：附录揭示 PSPI 与 NRS 在 SMP 上几乎不相关（甚至轻微负相关），虽然论文正确地仅将 PSPI 用于质量控制，但这也意味着

PSPI 与 NRS 的不一致也揭示了一个更深层的语义困境：现有自动疼痛评估社区长期以 FACS 派生指标作为监督信号，但其与患者真实体验的相关性有限；本论文选择以 NRS 为监督目标在临床上更合理，但这也意味着模型的输出在“疼痛强度”这一主观变量上会被自我报告的噪声所限制，性能天花板可能不仅源于算法，还源于标签本身的内在变异性。

- **通道路由策略的潜在信息损失**：虽然 RouteMix 让编码器能够接触多种模态组合，但每个 patch 只能路由 3 个通道，且同一 patch 内深度与热成像未必同时可见。论文未系统分析“同时需要深度和热成像才能判别的疼痛线索”在多大程度上被这一硬性通道预算牺牲；5-to-3 的压缩可能限制了跨模态互补性的充分挖掘。
- **模态身份的泛化问题**：IdEmb 在预训练阶段为原子通道 {R,G,B,Depth,Thermal} 学习嵌入向量；如果下游出现新的传感器模态（如近红外、肌电），需要重新预训练或设计扩展机制，论文未讨论这一扩展性。
- **伪模态重建质量未做定量评估**：ReMiX-Pseudo 依赖解码器生成的伪热成像与伪深度，但论文未报告这些重建信号的视觉质量或与真实热/深度信号的数值相似度。若伪模态存在系统性偏差，下游特征可能继承这些偏差；论文仅以最终分类性能间接证明其有效性，缺少因果链路验证。
- **时序建模较为粗糙**：虽然使用了 5 秒片段与多窗口注意力 MIL，但底层编码器依然是逐帧（或短片）的静态表征提取器，未在预训练阶段加入显式的时域掩码预测任务（如 VideoMAE 的 tube masking）或时间对比学习；疼痛作为时变过程，其时间演化信息可能未被充分利用。
- **计算可复现性信息不足**：如第 4 节所述，算力细节、预训练资源、超参数敏感度等均未披露，削弱了可复现性；这与当前顶会论文普遍要求的开放科学标准存在差距。
- **报告缺失**：论文未报告置信区间或显著性检验结果，也未公开代码和预训练权重，影响社区复现与后续研究。

## 9. 对相关领域的启示与潜在影响

- **范式启示**：ReMiX-MAE 的“训练时多模态、部署时单模态”理念对医疗人工智能具有普遍参考意义——现实临床环境往往只允许部署最轻量的传感器（如普通摄像头或单导联心电），而科研场景中已积累大量同步多模态数据；该工作提供了一个如何在不改变部署接口的前提下“榨取”多模态信号价值的方法学模板。
- **掩码建模的再思考**：将 MAE 掩码 M 与缺失模态声明 D 解耦，使得重建目标能精确地针对“被声明缺失”的模态，而不是简单地让模型重建所有不可见 patch。这一设计对多模态自监督学习社区具有独立的方法论贡献，可迁移到音频-视频、文本-图像等其他多模态场景。
- **临床疼痛评估的推进**：SMP 数据集的构建与公开（若最终发布）将填补临床面部疼痛数据库中纵向轨迹数据的空白，为后续研究者提供评估真实治疗方案变化的标准平台；同时，NRS 作为监督目标的选择，有助于推动领域从“AU/PSPI 间接代理”走向“患者自报真实体验”这一更贴近临床需求的评估范式。
- **数据增强与身份泄漏防范的示范**：论文中对外部身份 face-swap 增强的使用和“测试对象绝不参与增强”的约束，可作为面部视频分析研究中身份泛化设计的参考规范。

## 10. 总体评价与建议

**总体判断**：这是一项方法创新性强、实验设计认真、真实临床价值取向明确的论文。其核心贡献不在绝对性能的突破，而在于提出了一套在临床数据极度稀缺且训练-部署模态不对称条件下，有效利用多模态自监督信号的方法框架。它的主要局限——绝对性能偏低、统计验证不足、端到端对比缺失——均属于当前阶段该研究方向的共性挑战，而非方法上的根本缺陷。

**对后续研究的建议**：

1. **扩展数据集**：多中心采集更大规模、更多样化的临床疼痛视频数据，并在论文中报告年龄、性别、肤色、疼痛类型等亚组性能，以验证泛化性。
2. **增强统计严谨性**：在 LOSO 基础上引入多重随机种子、置换检验或置信区间估计，以支撑增量性能的显著性声明。
3. **加入端到端微调对比**：将冻结特征 + 轻量分类头协议与预训练模型继续微调（如 adapter、LoRA）的协议进行对比，厘清特征质量与分类器容量的贡献。
4. **量化伪模态质量**：在 SMP 或独立数据集上利用少量真实热/深度样本定量评估重建误差，建立“重建质量 → 分类增益”的因果链条。
5. **探索时间建模增强**：在预训练阶段加入时域掩码/对比任务，或在编码器中引入局部时序注意力，以更充分地利用疼痛的动态特征。
6. **开源与复现**：发布预训练权重、RouteMix 路由代码与 SMP 数据（脱敏后），便于领域内复用与后续改进。

## 结语

ReMiX-MAE 以精巧的方法设计回应了一个真实而困难的临床工程问题：如何让临床部署时几乎唯一可用的 RGB 摄像头，也能受益于训练阶段才出现的热成像与深度信息。该论文的价值不仅在于其自身结果的改善，更在于为“传感器稀缺的临床 AI”提供了一套可复用的多模态自监督迁移范式。尽管其绝对性能距离临床落地仍有明显距离，但从方法论和问题定位来看，这是一项推进该方向扎实前行的工作。
