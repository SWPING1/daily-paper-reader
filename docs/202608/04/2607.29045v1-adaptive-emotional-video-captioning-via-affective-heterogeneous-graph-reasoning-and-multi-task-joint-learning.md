## 摘要
情感视频描述（EVC）旨在以事实正确性和情感表现力来描述视频。它要求模型感知微妙、模糊且随时间变化的情感线索，并将其转化为自然语言，同时不削弱客观视觉内容。现有方法已逐步引入上下文注意力、情感解释、情感先验、动态情感感知和情感原因推理。然而，其中大多数仍依赖于全局情感向量或刚性层次先验。在近期方法中，树结构情感先验在心理情感类别与日常情感词之间建立了从粗到细的联系，但其硬性从属掩蔽可能在粗类别预测不准确时不可逆地抑制正确的情感词汇。它在表示真实视频中频繁出现的混合或重叠情感方面也受到限制。为解决这些问题，我们提出了SAGML，一种通过情感异构图和多任务语言建模的自适应EVC框架。SAGML不是将情感先验视为离散树，而是构建了一个包含目录级情感节点和词汇级情感词节点的软情感异构图。软门控作为连续偏置被注入视频到情感图的注意力中，使得视觉支持的情感词汇保持可恢复，而非被硬掩蔽移除。由此产生的情感表示与视觉标记一起输入因果语言解码器，而双目录头和词汇头对提示隐藏状态施加显式的情感分布学习。整个模型通过结合自回归字幕生成和情感分布监督的联合目标进行训练。SAGML为EVC提供了具有错误弹性和多情感感知的基线。

## Abstract
Emotional video captioning (EVC) aims to describe a video with both factual correctness and affective expressiveness. It requires a model to perceive subtle, ambiguous, and temporally varying emotional cues and translate them into natural language without weakening objective visual content. Existing methods have progressively introduced contextual attention, emotion interpretation, emotion priors, dynamic emotion perception and emotion-cause reasoning. Nevertheless, most of them still depend on either global emotion vectors or rigid hierarchical priors. In recent methods, the tree-structured emotion prior establishes a coarse-to-fine connection between psychological emotion categories and daily emotion words, but its hard subordinate masking may irreversibly suppress correct lexical emotions once the coarse category prediction is inaccurate. It is also limited in representing mixed or overlapping emotions that frequently occur in real videos. To address the issues, we propose SAGML, an adaptive EVC framework via affective heterogeneous graph and multi-task language modeling. Instead of treating the emotion prior as a discrete tree, SAGML constructs a soft affective heterogeneous graph containing catalog-level emotion nodes and lexical-level emotion word nodes. The soft gate is injected into video-to-emotion graph attention as a continuous bias, allowing visually supported lexical emotions to remain recoverable rather than being removed by a hard mask. The resulting affective representation is fed together with visual tokens into a causal language decoder, while dual catalog and lexical heads impose explicit emotion distribution learning on the prompt hidden states. The overall model is trained with a joint objective that combines autoregressive caption generation and emotion distribution supervision. SAGML provides an error-resilient and multi-emotion-aware baseline for EVC.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- **任务定义**：情感视频描述（EVC）要求在描述视频事实内容的同时，表达视频所蕴含的情感信息。与经典视频描述只关注物体、动作、场景等客观事实不同，EVC 需要感知面部表情、肢体动作、色调、场景语境等隐含情感线索，并产出既事实正确又情感丰富的自然语言描述。
- **核心挑战**：
  - 情感线索隐晦、模糊：同一视觉事件可能因上下文不同产生不同的情感解读；
  - 情感与事实语义不可分割：过度强调情感会造成事实性漂移，缺乏情感建模则描述平淡；
  - 真实视频常包含复合/变化情感：如生日场景同时包含喜悦与惊喜，告别场景可能存在悲伤、温暖与希望，单一主导情感假设难以刻画。
- **现有方法的不足**：
  - 早期方法依赖全局情感向量或刚性分层先验，表达能力受限；
  - 近期方法（如 EPAN）采用树状情感先验，建立从心理情感类别到日常情感词的从粗到细的映射，但其**硬性从属掩蔽**存在严重问题：
    - 一旦粗粒度类别预测不准确，其下属的词汇情感词可能被不可逆地抑制，即使视觉内容支持该词；
    - 树结构适合一对多关系，难以表达多类别词汇、语义相关情感词以及跨类别的混合情感；
  - 现有 EVC 模型的轻量级解码器语言能力不足，难以表达细微情感内容，尤其是低频情感词汇。
- **本文的解决思路**：提出 SAGML 框架，用**软情感异构图**替代离散树状先验，将情感先验改造为连续加权结构，使不确定性能在推理中传播而非被剪枝；同时首次将**大型语言模型（Qwen2.5）** 微调用于 EVC 任务，并通过多任务学习保持解码器的情感接地性。

## 2. 论文提出的方法论

**核心思想**：SAGML（Self-Adapting emotional video captioning via affective heteroGeneous graph reasoning and Multi-task Language modeling）包含三个可训练阶段：①轻量级视觉编码器；②图情感编码器（构建异构图、推理目录分布、生成软词汇门控）；③Qwen 解码器（连续前缀提示 + 双情感分类头监督）。

**关键技术细节与流程：**

1. **视觉编码**：
   - 均匀采样 N=30 帧，使用冻结的 CLIP ViT-B/32 提取 512 维外观特征；
   - 经线性投影和一层单头自注意力编码器，得到上下文视觉序列 V ∈ R^{N×D}，D=300。
   
2. **Qwen 对齐的情感节点初始化**：
   - 将情感字符串转换为带类型的短语（如 `emotion category: joy`、`emotion word: happy`）；
   - 用 Qwen 输入嵌入表对短语中各 token 的嵌入取平均，作为目录节点 E_c^0（34 个）和词汇节点 E_w^0（179 个）的初始化特征，维度 H=3584（Qwen2.5-Instruct 隐藏维度）。

3. **情感异构图构建**：三种互补关系构成统一拓扑：
   - **目录-目录关系 A_cc**：基于目录索引顺序的循环邻域高斯平滑（σ=1.5），使相邻类别的激活可相互传播；
   - **目录-词汇关系 A_cw**：从训练语料中统计共现（含加性平滑 α=0.1），支持多父词并给每对目录-词汇赋予非零关联；
   - **词汇-词汇关系 A_ww**：融合三种信号——Qwen 嵌入余弦相似度（β_L=0.5）、GloVe 相似度（β_G=0.3）、语料共现统计（β_R=0.2），阈值 τ=0.5 裁剪弱边；
   - 图传播：一次邻接矩阵传播 + 两层 MLP 投影，得到传播后的目录/词汇节点。
   
4. **目录情感感知**：
   - 视觉 token 作为 query，初始目录节点作为 key/value 进行交叉注意力；
   - 对输出做均值池化后经线性层得到目录 logits，softmax 后得目录分布 P_c（无 top-K 截断）。

5. **拓扑驱动的软词汇门控**：
   - 将目录分布经 A_cc 平滑后，再经 A_cw 传播到词汇节点：r_w = (P_c A_cc) A_cw；
   - 经线性层和 sigmoid 得门控 g，所有词汇节点的门控值严格为正（下界 ε=10^{-6}）；
   - 与硬掩码不同，软门控只是衰减词汇，不使其不可达。

6. **图偏置的词汇情感注意力**：
   - 视觉 token 作为 query，传播后的词汇节点作为 key/value；
   - 将 log(g) 广播到所有视觉位置并加到缩放点积注意力分数上：Softmax(QK^T/√H + 1_N log(g)^T)；
   - 输出与视觉残差融合并经 LayerNorm 得情感表示 H_e，即注意力具备"先验感知 + 视觉自适应"双重能力。

7. **Qwen 提示词解码器**：
   - 两个独立 MLP 将视觉和情感序列投影到 Qwen 隐藏维度，组成连续前缀 [T_v ; T_e]，与文本嵌入拼接输入 Qwen2.5-Instruct；
   - 采用 LoRA 参数高效微调（仅适配注意力层的 query/value 投影，rank=8，缩放因子 16，dropout 0.05），其余 Qwen 参数冻结；
   - 教师强制训练，损失只计算在文本 token 上（前缀位置的标签设为 -100）。

8. **提示级多任务情感预测**：
   - 取 Qwen 最终层在视觉/情感前缀 2N 个位置隐藏状态的均值 h_vibe；
   - 两个分类头分别输出目录级 logits ẑ_c 和词汇级 logits ẑ_w；
   - 训练目标由三部分组成：
     - 自回归字幕生成损失 L_LM；
     - 目录级 KL 散度情感分布损失；
     - 词汇级 KL 散度情感分布损失。
   - 总损失 L = L_LM + λ·L_EDL（λ 在前 5 个 epoch 为 0.2，之后为 0.5）。

## 6. 论文的主要结论与发现

1. **SAGML 全面超越现有方法**：在 EmVidCap 数据集上，较最强对比方法 MM-ECPE，Acc_sw 提高 6.7 分，Acc_c 提高 7.7 分，B-4 提高 4.6 分，CIDEr 提高 9.0 分，CFS 提高 8.6 分；在 EmVidCap-S 和 EmVidCap-L 上同样一致领先所有指标。
2. **软门控优于硬掩码**：目录分布经拓扑传播后的软门控是最大单一增益来源，将 Acc_sw/Acc_c 提升 4.0/4.4 分，CIDEr 提升 8.0 分，证实了"衰减而非删除"的有效性。
3. **图关系具有互补性**：词汇-词汇关系贡献最大（去掉后 CIDEr 从 76.9 降至 52.1），目录-目录关系提供类间不确定性传播；两者结合效果最佳。
4. **多任务情感分布学习有效**：目录级 EDL 提供粗粒度情感方向，词汇级 EDL 约束具体词汇选择，二者互补；完整双重目标在所有指标上最优。
5. **LLM 解码器优势明显**：Qwen 解码器相比 BLIP 在所有指标上更优（Acc_sw +1.8、Acc_c +2.6、CIDEr +5.5），且主要改善多词组合和参考描述一致性而非孤立词汇预测；但 BLIP 设置下的竞争力说明 SAGML 的优势并不完全依赖 LLM；
6. **图编码器对视觉特征形态不敏感**：即便使用 ResNet-152 特征，SAGML 仍能取得不错的性能，说明方法的稳健性；CLIP 特征给出最佳综合表现，但 ResNet+3D 在部分重叠度量上仍有优势，提示运动信息有补充价值。

## 7. 优点

- **方法论亮点**：
  - 以软异构图替代刚性树结构，具有理论上更优的误差鲁棒性——早期类别预测不确定性不再被硬性剪枝，而是通过连续门控保留后续修正空间；
  - 构建统一拓扑同时建模三种情感关系（包含 Plutchik 心理模型依据），对复合/重叠情感的表达更加自然；
  - 将 LLM 引入 EVC 时采用双级情感分布头直接监督提示隐藏状态（而非仅靠生成文本隐式学习），有效避免了"流畅但情感缺失"的典型问题；
  - 用 Qwen 嵌入初始化图节点，图推理与语言生成共享同一语义空间，减少表征错配。
- **工程与资源效率**：CLIP 特征离线提取；LoRA 仅微调注意力层 Q/V 投影，参数高效；提示级分类头只读取前缀状态，额外计算量很小。
- **实验设计**：消融逻辑清晰、层层递进，能精确归因每个组件的贡献；在三个数据规模/注释协议不同的基准上验证了方法的泛化性；同时报告语义、情感和混合指标，避免单一维度误导。

- **算力与可复现性**：训练需要 8×V100 且 30 个 epoch，对一般实验室复现门槛较高；论文未报告训练时长、模型总参数量、推理速度等关键工程指标。

- **对比公平性**：所有基线指标直接转录自原始论文，各方法使用的视觉编码器（ResNet vs CLIP）、解码器（LSTM vs Transformer vs LLM）和训练策略均不一致，因此性能增益可能部分来自架构差异而非图推理本身；论文未在统一后端下重新实现基线，削弱了对比的公平性。

- **超参数敏感性**：λ、τ、图传播尺度等关键超参数仅在一个数据集上调试，未报告它们在多个子集上的稳定性；τ 的消融显示其对 CIDEr 影响较大（0.4→0.5→0.6），说明方法对阈值选择较为敏感。

- **情感标签空间固定**：目录和词汇节点来自预定义集合（Plutchik 类 + 高频情感词），无法覆盖开放式情感词汇或新出现的情感表达；软门控虽缓解了硬剪枝问题，但仍受限于情感词汇表。

- **评估指标局限**：情感准确率基于封闭词汇表匹配，难以反映语义等价但表达不同的情感（如“非常高兴”与“乐坏了”）；缺少人工评估或 LLM 评判的语义/情感质量评测，可能遗漏生成文本的细粒度情感真实性。

- **数据集多样性不足**：EmVidCap-S/L 源自 MSVD 和 VideoEmotion-8，视频内容域有限（多为日常活动与短片），对长视频、复杂叙事或低资源情感场景的泛化性未得到验证。

## 9. 总体评价与未来方向

总体而言，SAGML 通过软异构图推理与 LLM 解码器的有机结合，在情感视频描述任务上取得了显著进展。其核心思想——以连续传播替代离散先验、以多任务情感监督引导生成——对后续研究具有启发意义。尽管在公平性、可复现性和评估维度上存在不足，该工作在方法论创新性和实验充分性上仍达到了较高水准。

未来研究方向可能包括：引入开放式情感词汇与动态词表扩展机制；探索可解释的图推理过程以增强生成依据的可信度；利用更强的多模态 LLM 直接进行端到端训练以取代两阶段特征提取；以及在更丰富、更真实的视频语料上验证方法的鲁棒性与普适性。
