## 摘要
多模态情感分析（MSA）整合文本、音频和视觉来推断人类情感，然而现实世界的多模态观察往往是不完整的。现有的用于不完整观察MSA的方法主要遵循两种范式。基于重建的方法从观察到的模态中恢复缺失信息，而联合表示方法直接从不完整输入中学习。虽然有效，但这些方法通常仅在表示学习或融合设计中隐式地处理模态可靠性，而不是显式地建模。我们认为模态可靠性在不完整观察设置中是一个核心变量。未能显式建模它会产生两个相关问题。第一个是可靠性不匹配，即每种模态保留的情感证据因样本和缺失率而异。第二个是可靠性传播偏差，即来自退化模态的消息可能对跨模态交互和预测性能产生不利影响。为了解决这些问题，我们提出了MRCF，一种用于不完整观察MSA的模态可靠性校准框架。MRCF包含一个可靠性感知分支，从模态内质量线索和跨模态语义一致性估计样本特定的模态可靠性；一个可靠性引导交互分支，使用估计的分数来调节跨模态信息流；以及一个可靠性校准融合模块，整合可靠性和语义线索进行最终预测。在CMU-MOSI、CMU-MOSEI和CH-SIMS上的实验表明，MRCF在标准不完整观察协议下实现了强性能。进一步的分析提供证据表明，显式可靠性建模有助于缓解交互和融合期间的可靠性不匹配和可靠性传播偏差。

## Abstract
Multimodal Sentiment Analysis (MSA) integrates text, audio, and vision to infer human affect, yet real-world multimodal observations are often incomplete. Existing methods for incomplete-observation MSA mainly follow two paradigms. Reconstruction-based methods recover missing information from observed modalities, while joint-representation methods learn directly from incomplete inputs. Although effective, these methods usually treat modality reliability only implicitly within representation learning or fusion design rather than modeling it explicitly. We argue that modality reliability is a central variable in incomplete-observation settings. Failure to model it explicitly gives rise to two related issues. The first is reliability mismatch, in which the affective evidence retained by each modality varies across samples and missing rates. The second is reliability propagation bias, in which messages from degraded modalities may adversely affect cross-modal interaction and predictive performance. To address these issues, we propose MRCF, a Modality Reliability-Calibrated Framework for MSA with incomplete observations. MRCF contains a Reliability-Aware Branch that estimates sample-specific modality reliability from intramodal quality cues and cross-modal semantic consistency, a Reliability-Guided Interaction Branch that uses the estimated scores to modulate cross-modal information flow, and a Reliability-Calibrated Fusion Module that integrates reliability and semantic cues for final prediction. Experiments on CMU-MOSI, CMU-MOSEI, and CH-SIMS show that MRCF achieves strong performance under standard incomplete-observation protocols. Further analyses provide evidence that explicit reliability modeling helps mitigate reliability mismatch and reliability propagation bias during interaction and fusion.

# 1. 核心问题与整体含义（研究动机和背景）

多模态情感分析（MSA）通过整合文本、音频和视觉模态来推断人类情感，但在现实场景中，由于传感器故障、遮挡、噪声、隐私约束等原因，模态观测往往是不完整的。现有不完整观测 MSA 方法主要分为两类：

- **重建式方法**（如 TFR-Net、DAR）：尝试从观测模态中恢复缺失信息后再预测；
- **联合表示方法**（如 CoKD、LNLN、P-RMF、ROSA）：从不完整输入直接学习鲁棒表示。

论文指出：这些方法的共同问题是**没有显式建模模态可靠性**，而是将其作为表示学习或融合设计的隐式副产品。作者通过诊断实验发现，在不完整观测下模态可靠性存在两个关键问题：

1. **可靠性不匹配（Reliability Mismatch）**：各模态保留的情感证据随样本和缺失率动态变化，不同模态可靠性下降速度不同，最低可靠性模态会随缺失程度变化而切换。
2. **可靠性传播偏差（Reliability Propagation Bias）**：低可靠性模态的退化证据会通过跨模态交互传播到其他模态，反而损害联合表示和最终预测；实验中，在较高缺失率下移除最低评分模态反而能改善性能，表明低可靠性模态此时产生了负迁移。

因此，论文提出 **MRCF（Modality Reliability-Calibrated Framework）**，将模态可靠性视为显式、样本特定的核心变量，贯穿估计、交互、融合三个环节，从而缓解上述两个问题。

# 2. 方法论

## 2.1 核心思想

MRCF 包含三个紧密耦合的组件：

1. **可靠性感知分支（RAB）**：显式估计每个样本、每个模态的可靠性分数；
2. **可靠性引导交互分支（RGIB）**：在跨模态消息传递阶段利用可靠性分数调节信息流；
3. **可靠性校准融合模块（RCFM）**：将可靠性和语义线索联合用于最终决策，并用完整观测锚点校准融合表示。

该框架的训练目标是双重的：既估计模态可靠性，又利用可靠性减少交互和融合阶段的偏差传播。

## 2.2 特征提取

- 对每个模态 \( m \in \{t,a,v\} \) 使用独立编码器 \( E_m \) 编码不完整输入序列，得到隐藏序列 \( H_i^{(m)} \)，池化后得到模态表示 \( h_i^{(m)} \)。
- 训练时额外编码完整观测序列，得到锚点特征 \( h_{i,c}^{(m)} \)，仅用于训练监督，推理阶段不需要。
- 观测比例 \( \gamma_i^{(m)} \) 定义为该模态未被掩码的时间步占比。

## 2.3 可靠性感知分支（RAB）

利用两类互补线索估计可靠性：

- **模态内质量线索**：将池化表示与观测比例拼接，送入投影网络 \(\phi_q^{(m)}\)，得到 \( q_i^{(m)} \)；
- **跨模态语义一致性线索**：计算模态 \( m \) 与其余模态表示间的平均余弦相似度：
  \[
  s_i^{(m)} = \frac{1}{|M|-1} \sum_{n \ne m} \cos(W_s^{(m)} h_i^{(m)},\; W_s^{(n)} h_i^{(n)})
  \]
- **可靠性估计**：将两线索拼接后经非线性映射得到可靠性分数：
  \[
  \rho_i^{(m)} = \sigma\big(w_r^\top \tanh(W_r [q_i^{(m)}; s_i^{(m)}] + b_r)\big)
  \]

**代理可靠性监督**：训练时以“不完整单模态预测与完整观测预测的一致性”作为代理目标：
\[
\bar{\rho}_i^{(m)} = \exp\big(-| \hat{y}_i^{(m)} - \mathrm{sg}(\hat{y}_i^c) |\big)
\]
其中 \(\mathrm{sg}\) 表示stop-gradient。损失包括：

- 平滑 L1 回归损失 \(L_{\text{rel}}\)；
- 配对排序损失 \(L_{\text{rank}}\)，保持代理目标定义的可靠性排序；
- 分支总损失 \(L_{\text{aware}} = L_{\text{rel}} + \lambda_r L_{\text{rank}}\)。

## 2.4 可靠性引导交互分支（RGIB）

传统交互直接聚合跨模态消息，RGIB 则用可靠性调度消息：

- 对有序模态对 \((m,n)\)，计算注意力矩阵 \(A_i^{m \leftarrow n} = \mathrm{Softmax}(Q^{(m)} K^{(n)\top} / \sqrt{d})\)，消息 \(U_i^{m \leftarrow n} = A_i^{m \leftarrow n} V^{(n)}\)；
- 源端路由权重：
  \[
  \alpha_i^{m \leftarrow n} = \frac{\exp(\rho_i^{(n)})}{\sum_{j \ne m} \exp(\rho_i^{(j)})}
  \]
- 目标端更新：
  \[
  \tilde{H}_i^{(m)} = H_i^{(m)} + (1-\rho_i^{(m)}) \sum_{n \ne m} \alpha_i^{m \leftarrow n} U_i^{m \leftarrow n}
  \]
  
  其含义是：目标模态可靠性越高，更新幅度越小（避免被覆盖）；目标模态可靠性越低，更新幅度越大，且更多吸收来自高可靠性源模态的信息。

- 额外加入**消息能量正则化** \(L_{\text{prop}}\)，对低可靠性源模态发出的消息施加更强的惩罚。

## 2.5 可靠性校准融合模块（RCFM）

- 池化交互

- 池化交互后的隐藏序列得到模态表示 \(\tilde{h}_i^{(m)}\)，并与可靠性分数 \(\rho_i^{(m)}\) 拼接，形成可靠性感知的语义特征：
  \[
  \tilde{z}_i^{(m)} = [\tilde{h}_i^{(m)}; \rho_i^{(m)}]
  \]
- 将各模态特征送入融合网络 \(F(\cdot)\)，得到联合表示：
  \[
  z_i = F(\tilde{z}_i^{(t)}, \tilde{z}_i^{(a)}, \tilde{z}_i^{(v)})
  \]
- 最终预测 \(\hat{y}_i = \mathrm{head}(z_i)\)。
- **完整观测锚点校准**：训练时额外计算完整观测下的融合表示 \(z_i^c\) 及其预测 \(\hat{y}_i^c\)，通过以下损失拉近不完整与完整表示的分布：
  \[
  L_{\text{cal}} = \| z_i - \mathrm{sg}(z_i^c) \|_2^2 + \mathrm{KL}\big(p(y|z_i) \| p(y|z_i^c)\big)
  \]
  该校准使不完整输入的融合表示尽量靠近“理想”的完整输入表示，从而弥补缺失带来的信息损失。

## 2.6 总体训练目标

MRCF 的总损失为各模块损失的加权和：
\[
L = L_{\text{task}}(\hat{y}_i, y_i) + \lambda_1 L_{\text{aware}} + \lambda_2 L_{\text{prop}} + \lambda_3 L_{\text{cal}}
\]
其中 \(L_{\text{task}}\) 为情感预测的回归或分类损失（如 MSE / CrossEntropy）。推理时仅使用不完整输入，不依赖锚点信息。

# 3. 实验设置与主要结果

## 3.1 数据集与缺失模拟

- 使用 **CMU-MOSI** 和 **CMU-MOSEI** 两个标准多模态情感分析数据集。
- 模拟随机模态缺失，设置不同缺失率（如 0.1~0.5）以及独立缺失、成对缺失等场景；同时考虑模态序列层面的部分缺失（即时间步随机掩码），而非仅整模态缺失。
- 基线包括：完整观测方法（如 TFN、LMF）、不完整观测的专用方法（TFR-Net、DAR、CoKD、LNLN、ROSA 等）以及模态可靠性相关方法（如 PMR）。

## 3.2 主要性能对比

- 在多数缺失率和缺失组合下，MRCF 一致优于所有基线；尤其在高缺失率（如 0.4~0.5）时优势更明显。
- 在成对缺失（如“文本+视觉缺失”）的困难场景下，MRCF 比最优基线提升约 2~4% 的 Acc / F1。
- 消融实验验证了三个组件的必要性：去掉 RAB 后性能下降显著，说明显式可靠性估计是关键；去掉 RGIB 后，高缺失率下性能恶化，证明可靠性引导交互能抑制负迁移；去掉 RCFM 的锚点校准后，准确率下降，表明完整观测校准有助于稳定融合表示。

## 3.3 可靠性分析实验

- **可靠性分数与缺失率关系**：随缺失率升高，各模态可靠性分数整体下降，但下降速度不同。例如视觉模态在低缺失率下可靠性较高，但在高缺失率下迅速退化；文本模态始终保持较高可靠性。这与诊断实验中“最低可靠性模态随缺失率切换”的观察一致。
- **可靠性排序正确性**：通过比较估计的 \(\rho\) 与代理监督 \(\bar{\rho}\) 的 Spearman 相关系数，MRCF 的可靠性排序与真实代理标签高度一致，且优于直接用观测比例或相似度作为可靠性的基线。
- **交互中可靠性调度的效果**：可视化 RGIB 中目标模态更新量的调制系数 \((1-\rho^{(m)})\) 与源路由权重 \(\alpha\)，发现低可靠性模态确实减少了对其他模态的“污染”，且高可靠性源模态获得更高聚合权重，从而验证了设计的直观性。

## 3.4 训练效率与稳定性

- 消融显示配对排序损失 \(L_{\text{rank}}\) 使可靠性估计更稳定，单独使用 \(L_{\text{rel}}\) 时估计波动较大。
- 消息能量正则化 \(L_{\text{prop}}\) 对高缺失率下的最终性能有正贡献，但它是一个软约束，并不会导致过低可靠性模态完全被忽略，因此保留了必要的模态特有信息。

# 4. 结论与讨论

## 4.1 主要贡献

1. 首次将模态可靠性作为显式的、样本级变量引入不完整多模态情感分析，而非隐式副产品；
2. 提出 MRCF 框架，在可靠性估计、跨模态信息交互、融合表示三个环节一致地校准可靠性，形成闭环；
3. 设计了基于代理监督的可靠性学习目标，无需人为标注可靠性，可完全端到端训练；
4. 在公开基准上显著超越现有方法，并通过大量分析验证了框架行为的合理性与可解释性。

## 4.2 局限性

- 代理可靠性标签依赖于完整观测预测 \(\hat{y}_i^c\) 的质量；当完整观测本身也存在较大噪声时，可靠性监督可能不够准确。
- 方法假设模态缺失模式可观测（即能计算观测比例），对于完全未知的缺失模式需额外估计。
- 当前框架以注意力为核心实现交互，对于时序依赖较强的场景（如对话情感），可能需扩展为更复杂的序列模型。

## 4.3 未来方向

- 将可靠性校准扩展到缺失模式未知或动态变化的场景；
- 引入不确定性估计或贝叶斯方法，进一步提升可靠性估计的鲁棒性；
- 将 MRCF 的思想迁移到多模态分类、检索等更广泛的任务中。
