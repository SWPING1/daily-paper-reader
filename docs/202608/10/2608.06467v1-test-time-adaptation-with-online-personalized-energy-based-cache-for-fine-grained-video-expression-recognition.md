## 摘要
视频中的面部表情识别（FER）具有挑战性，因为模型必须识别在不同个体间变化的微妙、随时间演变的情感状态。尽管视觉-语言模型提供了可迁移的视觉-语义表示，但在推理时，基于受试者无关数据训练的模型在受试者特定的分布偏移下往往会性能下降。现有的测试时自适应（TTA）方法通常在推理期间更新模型参数，从而增加计算成本和延迟。基于缓存的方法避免了参数更新，但通常需要足够的目标样本来形成可靠的类原型，这在自适应早期以及对于罕见类别来说是困难的。我们引入了基于能量的缓存个性化（EB-CaP），一种面向视频FER的基于受试者的在线TTA方法，它为每个目标视频生成个性化的类特定原型。EB-CaP使用一个轻量级的基于能量的模型，从当前未标记的视频中采样原型，并在线填充个性化缓存，而无需积累大量目标数据或存储多样的源原型。其能量函数仅依赖于预训练的CLIP：目标视频嵌入与类别文本嵌入之间的相似性引导原型采样。同时，正缓存和负缓存存储可靠和不确定的目标嵌入。自适应熵门根据不断变化的置信度分布控制缓存更新，而多样性门限制冗余样本。最终预测结合了缓存派生分数与当前CLIP分数。在BioVid、StressID和BAH上的实验表明，EB-CaP在保持较低计算和内存开销的同时，优于最先进的TTA方法。代码可在https://github.com/MasoumehSharafi/EB-CaP获取。

## Abstract
Facial expression recognition (FER) in videos is challenging because models must identify subtle, temporally evolving affective states that vary across individuals. Although vision-language models provide transferable visual-semantic representations, models trained on subject-independent data often degrade under subject-specific distribution shifts at inference time. Existing test-time adaptation (TTA) methods commonly update model parameters during inference, increasing computational cost and latency. Cache-based methods avoid parameter updates, but they usually require enough target samples to form reliable class prototypes, which is difficult early in adaptation and for rarely observed classes. We introduce Energy-Based Cache Personalization (EB-CaP), a subject-based online TTA method for video FER that generates class-specific prototypes personalized to each target video. EB-CaP uses a lightweight energy-based model to sample prototypes from the current unlabeled video and populate a personalized cache online, without accumulating large amounts of target data or storing diverse source prototypes. Its energy function relies only on pretrained CLIP: similarities between the target video embedding and class text embeddings guide prototype sampling. In parallel, positive and negative caches store reliable and uncertain target embeddings. An adaptive entropy gate controls cache updates according to the evolving confidence distribution, while a diversity gate limits redundant samples. Final predictions combine cache-derived scores with the current CLIP scores. Experiments on BioVid, StressID, and BAH show that EB-CaP outperforms state-of-the-art TTA methods while maintaining low computational and memory overhead. Code is available at https://github.com/MasoumehSharafi/EB-CaP.

### 1. 论文的核心问题与整体含义

- **研究背景**：视频中的细粒度表情识别（FER）需要捕捉微妙的面部运动、表情强度和时间演化等线索，但相同的情感状态在不同个体上表现差异巨大，而不同状态又可能呈现出相似的面部模式。因此，在固定源受试者上训练的模型往往难以泛化到未见过的目标个体。
- **核心问题**：现有测试时自适应（Test-Time Adaptation, TTA）方法存在两类主要缺陷：
  - **基于优化的方法**（如熵最小化、提示微调）在推理期间反复更新模型参数，导致计算开销大、延迟高，且当目标数据模糊或预测错误时可能引发模型漂移；
  - **基于缓存的方法**虽避免参数更新，但需要积累足够的未标记目标样本才能构建可靠类原型，存在"冷启动"问题——在自适应初期或某些类别极少出现时效果不佳。
- **文章定位**：提出一种面向视频FER的**基于受试者的在线TTA方法EB-CaP**，在不更新模型参数的前提下，通过轻量能量模型从当前未标记视频中在线采样个性化类原型，解决缓存冷启动问题，兼顾性能与效率。

### 2. 论文提出的方法论

#### 2.1 整体框架
EB-CaP采用冻结的CLIP模型作为骨干（图像编码器 + 文本编码器），并配合一个在源数据上训练后冻结的时间Transformer编码器，对每条目标视频的时序窗口生成视频级表示。测试时通过三类缓存（个性化采样缓存、正目标缓存、负目标缓存）与CLIP分数的融合来实现自适应预测，全程不更新任何模型参数。

#### 2.2 个性化采样缓存（Personalized Sampled Cache）
- **核心思想**：利用能量模型（EBM）从当前未标记视频表示出发，为每个类别采样多个类条件嵌入原型。
- **能量函数**：基于冻结识别模型的类兼容性得分定义：
  \[
  E_\theta(z, c) = -z^\top e_c
  \]
  其中 \(e_c\) 是类别 \(c\) 的归一化文本嵌入，能量越低表示表示 \(z\) 与类别 \(c\) 的兼容性越高。
- **采样过程**：对每个类别，使用**随机梯度Langevin动力学（SGLD）**初始化一条从当前视频表示 \(z_{\text{tgt}}\) 出发的马尔可夫链：
  \[
  \hat{z}_{k+1} = \hat{z}_k - \frac{\alpha}{2} \nabla_{\hat{z}_k} E_\theta(\hat{z}_k, c) + \sqrt{\alpha} \sigma \epsilon_k
  \]
  其中 \(\alpha\) 为步长，\(\sigma\) 控制噪声幅度，\(\epsilon_k \sim \mathcal{N}(0,I)\)。每步后归一化，当采样嵌入被预测为条件类别c时及早停止，以鼓励多样性并减少迭代次数。
- **效果**：该缓存对每个视频实时重建，覆盖所有类别，从根本上缓解了缓存冷启动问题。

#### 2.3 正/负目标缓存
- **正缓存 \(K_p\)**：存储高置信度（低熵）的目标嵌入及其伪标签，每类容量有限。
- **负缓存 \(K_n\)**：存储不确定或类别冲突的目标嵌入，作为"负证据"（取该样本最不可能的类别），每类容量有限。
- 两个缓存均在同一受试者内跨视频累积，切换到新受试者时重置。

#### 2.4 自适应熵门与多样性门
- **自适应熵门**：从预测概率计算熵以判断置信度。每个视频前五个时间窗口使用固定阈值（正缓存0.5、负缓存0.8），之后根据当前视频内已观察熵的运行均值μ和标准差σ自适应调整：\(\tau_p = \mu - \sigma\)，\(\tau_n = \mu + \sigma\)。熵低于\(\tau_p\)的样本进正缓存，介于两者之间的进负缓存，高于\(\tau_n\)的丢弃。
- **多样性门**：计算候选样本加入前后对应类别分区嵌入的**特征方差增益**\(\Delta D = D_{\text{after}} - D_{\text{before}}\)，仅当\(\Delta D > 0\)时保留样本，避免冗余高相关时间窗口主导缓存。

#### 2.5 缓存检索与最终预测
- 对当前视频表示，计算其与三类缓存中所有嵌入的余弦相似度，按类别聚合得到三个缓存分数 \(s_s\)、\(s_p\)、\(s_n\)。
- 最终融合分数为：
  \[
  s_{\text{fuse}} = s_{\text{tgt}} + s_s + s_p - s_n
  \]
  取最高分数对应的类别作为最终预测。
