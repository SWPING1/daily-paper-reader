## 摘要
机器学习模型在训练过程中数据缺失时应该学习什么？我们从动力系统的角度审视学习过程，将数据缺失视为一种结构性的驱动损失，限制了参数误差动力学的可控性，并最终推导出具有李雅普诺夫稳定性特征的适应机制，该机制在部分、间歇性可观测性下以保留学习连贯性的方式调节模型更新。在循环激励下，我们的分析提供了ISS型残差到状态的界限，该界限与损失残差和预处理更新几何之间的有界闭环失配相关。我们在多模态情境下评估了我们的方向性可观测性感知自适应学习方法的有效性，强化了其在病理性稀疏领域和问题中促进学习连贯性和稳定性的前提。

## Abstract
What should a machine learning model learn when data is missing during training? We look at the learning process from a dynamical systems perspective, cast data missingness as a structured loss of actuation that limits controllability of the parameter error dynamics, and ultimately derive adaptation mechanisms with Lyapunov stability characteristics that throttle model updates in ways that preserve learning coherence under partial, intermittent observability. Under recurrent excitation, our analysis provides ISS-type residual-to-state bounds with respect to a bounded closed-loop mismatch between the loss residual and the preconditioned update geometry. We evaluate the efficacy of our directional observability-aware adaptive learning approach on multimodal contexts, reinforcing its premise in promoting learning coherence and stability even in pathologically sparse domains and problems.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将模型参数视为系统状态（state），学习率、更新方向、正则化强度视为控制输入（control inputs）。缺失数据既影响反馈信号，也改变“驱动几何”（actuation geometry）。
- 通过分析参数误差动态的复位向量，推导出观测感知的自适应学习律，从而只在数据支持的参数方向上进行必要的更新，避免无依据的参数运动。

### 2.2 关键技术细节

- **标量观测感知自适应（prototypic scalar adaptation）**：
  - 在线性回归示例中，定义瞬时观测特征能量 γ_t = ‖x̃_t‖²；
  - 用与观测程度相关的增益 α_t = η / (ε + γ_t) 替代固定学习率 η，其中 ε > 0；
  - 更新规则：w_{t+1} = w_t + α_t x̃_t(y_t − ⟨w_t, x̃_t⟩)。
  - 该更新能保证有效更新量随观测度下降而趋近于零，从而避免在部分驱动时过度移动可见坐标。
  - 通过 Lyapunov 函数 V_t = ‖e_t‖² 和 Young 不等式导出 ISS 型有界性：‖e_t‖ ≤ ρ^t‖e_0‖ + C sup|d_τ|。

- **方向性观测感知自适应（directional observability-aware learning）**：
  - 定义灵敏度向量 g_t = ∇_w ŷ(w_t, x̃_t)，其秩一驱动算子为 A_t = g_t g_t^T；
  - 用指数移动平均积累观测历史：S_t = βS_{t−1} + (1−β)A_t，并形成正则化观测矩阵 B_t = S_t + εI；
  - 方向性自适应更新律为：w_{t+1} = w_t − η B_t^{-1} ∇_w ℓ_t。
  - B_t 类似于控制论中的可观性 Gramian，决定了哪些参数方向最近被数据支持。
  - 该更新律的自然变分解释是：在减小损失的同时，用 B_t 定义的几何约束参数运动；位移 δw 通过求解带二次惩罚项的优化问题给出。

- **闭环解释与近似方法**：
  - 更新律被解释为闭环自适应系统：B_t^{-1} 是数据依赖的时变控制律，非外部预设；
  - 实际大规模模型中可采用对角近似、块对角近似（如按层或注意力头分块）、低秩近似，以保持核心稳定机制而降低计算复杂度。

### 2.3 稳定性分析核心结果

- 在若干假设下（有界灵敏度、扇形有界标量反馈、先验有界闭环残差失配、窗口化有效可观测性），论文给出了**窗口化残差到状态（residual-to-state）的 ISS 型有界性**：
  - ‖e_t‖ ≤ A q^{⌊t/T⌋} ‖e_0‖ + L δ，其中 q ∈ (0,1)；
  - 该结果在有限维参数空间或有限维不变活跃子空间上成立。
- 对于线性回归、核方法、通用梯度网络等特殊情况，相应的可观测性条件和更新律被逐一解析；对真无限维 RKHS，则不宣称有限窗口收缩保证。

- **应用范围界定模糊**：论文处理的是训练阶段的数据缺失，但未讨论测试阶段是否也发生缺失，也未说明如何将模型部署到长期部分可观测的环境中。对于“观测矩阵随时间变化”的在线设置，理论只保证有限时间窗口内的有界性，而窗口长度如何确定、在无限长运行下是否稳定等问题未给出明确答案。

## 9. 个人评价与思考

本文的价值在于提出了一个看待缺失数据学习的全新视角——将参数更新视为受控动力学系统，缺失数据导致的“驱动缺失”被形式化为控制输入的部分不可用。这一视角弥补了传统统计方法只关注预测分布而不关注学习动态稳定性的空白。论文的更新规则（尤其是方向性观测感知方式）在直觉上非常清晰：只在数据支持的方向上进行更新，避免无据的参数漂移。这一点在实验中得到了证实，尤其是方向性方法在非线性模型上甚至优于全观测 SGD，说明其具有潜在的正则化或条件化益处。

然而，论文目前更像是一篇“概念验证 + 理论框架”性质的工作，距离实用化仍有距离。未来若能做到以下三点，将大幅提升其影响力：一是与主流缺失数据方法做系统公平对比；二是给出超参数的自适应设置或高效调优方案；三是将理论从有限维参数空间扩展到更实际的无限维或大模型场景，并针对随机优化（如 Adam、动量 SGD）进行推广。另外，控制论视角与贝叶斯方法并不是互斥的，若能讨论两者结合的可能性（例如用观测感知的先验约束后验更新），或许能开辟更有趣的研究方向。

总体而言，本文选题新颖、理论扎实、实验有说服力，虽然存在若干未充分讨论之处，但仍是缺失数据学习领域一篇值得精读的论文。
