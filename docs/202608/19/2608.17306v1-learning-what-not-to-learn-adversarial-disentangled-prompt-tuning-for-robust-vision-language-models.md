## 摘要
虽然对抗提示调优可以高效地增强视觉语言模型的鲁棒性，但我们发现现有方法会加剧对已知类别的鲁棒泛化过拟合，导致随着训练进行，模型对未知类别的对抗样本的性能迅速下降。我们通过实验发现，这种退化源于模型倾向于学习伪鲁棒特征（即不可泛化的捷径）。为缓解这一问题，我们提出了ADAPT（对抗解耦提示调优），一个遵循“学习不学什么”哲学的鲁棒提示调优框架。具体而言，ADAPT使用双提示机制，包含一个目标提示和一组诱饵提示。在训练过程中，诱饵提示被引导去捕获多样化的伪鲁棒特征，而目标提示则被约束在嵌入空间中与诱饵正交，以学习鲁棒特征。通过将鲁棒特征与伪鲁棒特征解耦，ADAPT有效防止了鲁棒泛化过拟合。我们进一步提供了分析，表明正交损失限制了伪鲁棒特征变化对未知类别的影响，从而给出了测试误差保证。实证上，大量实验表明ADAPT显著提高了目标提示在未知类别上的鲁棒性。代码可在 https://github.com/cheny02/ADAPT-ACMMM2026 获取。

## Abstract
While adversarial prompt tuning can enhance robustness of vision-language models efficiently, we find that existing methods aggravate robust generalization overfitting on seen classes, leading to a rapid degradation in performance against adversarial examples of unseen classes as training progresses. We empirically identify that this degradation stems from the tendency of the model to learn pseudo-robust features (i.e., non-generalizable shortcuts). To mitigate this, we propose ADAPT (Adversarial Disentangled Prompt Tuning), a robust prompt tuning framework following the philosophy of ``Learning What Not to Learn''. Specifically, ADAPT uses a dual-prompt mechanism with a target prompt and a pool of decoy prompts. During training, the decoy prompts are guided to entrap diverse pseudo-robust features, while the target prompt is constrained to be orthogonal to the decoys in the embedding space to learn robust features. By disentangling the robust features from the pseudo-robust features, ADAPT effectively prevents robust generalization overfitting. We further provide an analysis showing that the orthogonal loss bounds the effect of shifts in pseudo-robust features on unseen classes, yielding a testing error guarantee. Empirically, extensive experiments demonstrate that ADAPT substantially improves the robustness of the target prompt on unseen classes. The code is available at https://github.com/cheny02/ADAPT-ACMMM2026.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **视觉语言模型（VLM）的脆弱性**：以CLIP为代表的视觉语言模型虽然具有强大的零样本能力，但对视觉对抗扰动极其脆弱，在安全关键场景（如自动驾驶、医疗）中的应用受到限制。
- **对抗训练与提示调优的结合**：对抗训练（AT）是防御对抗攻击最有效的手段，但全参数对抗微调的计算成本过高。因此，参数高效的对抗提示调优（Adversarial Prompt Tuning）成为兼顾效率与鲁棒性的重要研究方向。
- **发现新现象——鲁棒泛化过拟合**：论文发现现有对抗提示调优方法存在一种与此前已知的鲁棒过拟合（robust overfitting）不同的现象：在训练过程中，模型在基类（可见类）上的鲁棒训练/测试损失持续下降或稳定，但在新类（不可见类）上的鲁棒测试损失却显著上升——即鲁棒性无法泛化到未见过的语义类别。
- **根因分析**：该现象源于模型的捷径学习（shortcut learning），即模型倾向于学习一种“伪鲁棒特征”（pseudo-robust features）——这些特征能有效应对基类上的对抗攻击，但不具备跨类别的语义泛化能力，是一种对攻击算法特定模式的“逆向工程”。
- **核心命题**：论文提出应遵循“学习不学什么”（Learning What Not to Learn）的哲学，主动识别并摒弃这些不可泛化的伪鲁棒特征，从而实现真正的鲁棒性泛化。

### 2. 论文提出的方法论：核心思想、关键技术细节与公式流程

#### 核心思想
- **ADAPT（Adversarial DisentAngled Prompt Tuning）**：通过将“要学的鲁棒特征”与“不要学的伪鲁棒特征”在嵌入空间中显式解耦，防止鲁棒泛化过拟合。

#### 双提示机制（Dual-Prompt Mechanism）
- **目标提示（Target Prompt）Pₜ**：即真正用于分类推断的提示，学习通用、可迁移的鲁棒语义特征。
- **诱饵提示池（Pool of Decoy Prompts）P_d = {P¹_d, ..., P^K_d}**：一组与目标提示结构相同的可学习提示，专门用于“诱捕”各类伪鲁棒特征（即捷径）。每个诱饵提示独立初始化，仅在自身被采样到的迭代中更新（随机采样），从而捕获多样化的捷径方向。

#### 诱饵提示的训练目标（Shortcut Trap）
诱饵提示需要满足两个条件：
1. 能在基类的对抗样本上取得好的分类效果，从而“吸收”伪鲁棒特征：
   L_d^ce = L_ce(x_adv, t_d, y)（3）
2. 必须偏离通用语义锚点（即手工提示的文本嵌入t_H），确保学到的确实是非语义的捷径特征：
   L_dis = cos(t_d, t_H)（2）
   
   总体目标：
   L_d^total = L_d^ce + α·L_dis（4）

#### 目标提示的训练目标（Disentanglement）
1. **正交损失**：目标提示的全局文本嵌入 ¯tₜ 必须与诱饵提示的全局嵌入 ¯t_d 正交（对诱饵使用stop-gradient，仅更新目标提示）：
   L_orth = cos²(¯tₜ, sg(¯t_d))（5）
2. **语义损失**：目标提示需与手工提示（通用语义锚点）保持接近，以避免灾难性遗忘预训练知识：
   L_sem = ‖tₜ − t_H‖₁（6）

   总体目标：
   L_t^total = L_t^ce + β·L_sem + λ·L_orth（7）

#### 算法流程（文字描述）
1. 使用当前目标提示生成对抗样本x_adv（3步PGD）；
2. 从诱饵池中均匀采样一个诱饵提示，用公式(4)更新该诱饵提示；
3. 用公式(7)更新目标提示；
4. 迭代直至收敛。推理时仅使用目标提示，不增加任何推理开销。

#### 理论保证（Theorem 3.2）
- 在特征空间可分解为语义子空间S与捷径子空间U的假设下，若目标提示与语义锚点的偏差ε_sem足够小，且目标提示在捷径子空间上的投影ε_U被正交损失限制，则目标分类器对捷径子空间的任意扰动不敏感，新类测试错误率有上界ζ。

1. **发现新现象**：首次识别并定义了对抗提示调优中的“鲁棒泛化过拟合”（robust generalization overfitting），即模型在可见类上鲁棒性良好但在不可见类上鲁棒性显著下降，其根因是伪鲁棒特征（捷径）的学习。
2. **方法有效性**：ADAPT通过诱饵提示池主动“吸收”各类伪鲁棒特征、并通过正交约束将目标提示与捷径解耦，显著提升了新类上的鲁棒性。

5. **推理零开销**：双提示机制仅用于训练，推理时无需额外计算。

- **概念创新**：“学习不学什么”思想在对抗提示调优中首次得到系统化应用，将鲁棒泛化失败归因于伪鲁棒特征而非传统意义上的过拟合，给出了新的理论视角。
- **机制设计巧妙**：诱饵提示主动“吸引”捷径 + 目标提示正交避让，形成一种“主动拒绝学习”的机制；多诱饵池+随机采样策略使得诱饵能覆盖多样化的捷径方向。
- **理论分析扎实**：提供了严格的定理证明，阐明了语义损失与正交损失如何共同限制新类的泛化误差，做到了理论上有保证、实验上可验证。
- **推理时零额外开销**：诱饵仅在训练中使用，不增加部署成本，实用性较强。
- **多模态扩展**：提供ADAPT_M版本，在多模态提示调优基线上也取得一致的领先，增强方法泛用性。
- **补充实验翔实**：包括图像侧投影分析对理论假设的经验验证，以及针对ADAPT量身定制的自适应攻击（DGAA）评估，体现了较高的严谨性。
- **代码开源**：提供可复现的代码仓库。

### 8. 不足与局限

- **训练成本增加**：训练内存约为APT的2.4倍（ImageNet上），训练时间约增加65%，在资源受限场景下可能成为瓶颈。
- **基准对比不够全面**：未与近年新提出的测试时提示调优（如TAPT、R-TPT）及其他近期的对抗提示调优方法进行对比。
- **理论假设的理想化**：语义/捷径子空间的正交分解是一个理想化抽象，虽然提供了经验验证，但真实CLIP特征中二者的纠缠可能更加复杂；定理成立条件（如γ > 2ε_sem + 2Bε_U）在极端情况下未必容易满足。
- **超参数数量较多**：引入了α、β、λ、K等多个额外超参数，尽管敏感性分析显示中等范围内较稳定，但最优值仍需调参。
- **诱饵提示池模型解释性有限**: 论文通过t-SNE可视化和图像侧投影分析提供了间接验证，但对"诱饵捕获的具体是什么捷径"缺乏更直接的语义层面的证据（如图像级扰动可视化）。
- **仅关注CLIP系模型**：未覆盖更大规模的视觉-语言模型（如LLaVA等生成式VLM）。
- **单次运行**：鉴于对抗训练的随机性，报告结果可能缺乏多次随机种子下的方差估计。
