## 摘要
近期关于多模态情感分析（MSA）的研究主要关注在不完整数据下从语言、视觉和声学模态中学习，以推断人类情感。大多数研究通常通过重建模态特征或设计复杂的融合机制来补偿缺失信息。然而，由于部分观测到的多模态证据缺乏高层语义基础，这些方法仍然受到虚假生成和噪声引导的影响。为解决这些问题，我们提出 SemMSA，一个潜在语义辅助框架，它利用 LLM 构建丰富的与情感相关的语义，并通过无锚点谱对齐与所有模态充分融合。它主要包括跨模态语义精炼（CSR）和跨模态谱对齐（CSA）。具体而言，CSR 首先通过相应的适配器自适应地提取视觉和声学表示，以在冻结的 LLM 嵌入空间中与语言形成统一的多模态前缀。然后，它通过一种 token 高效的潜在精炼过程迭代地产生连续的判别性语义状态，而无需解码显式文本。接下来，CSA 通过增强其核 Gram 矩阵的主导谱分量，同时将精炼后的语义与所有模态对齐。这捕获了所有表示之间的全局非线性依赖关系，而不依赖于预定义的锚模态。此外，实例级谱分离约束保持了跨样本判别性，并缓解了表示坍缩。在 SIMS、MOSI 和 MOSEI 基准上的大量实验表明，SemMSA 达到了最先进的性能。

## Abstract
Recent research on Multimodal Sentiment Analysis (MSA) has focused on learning from language, visual, and acoustic modalities with incomplete data to infer human sentiment. Most studies typically compensate for missing information by reconstructing modality features or designing complicated fusion mechanisms. However, these methods still suffer from spurious generation and noisy guidance due to the lack of high-level semantic grounding in partially observed multimodal evidence. To address these issues, we propose SemMSA, a latent semantic-aided framework that constructs rich sentiment-relevant semantics with LLMs, fully integrating with all modalities via anchor-free spectral alignment. It mainly consists of Cross-modal Semantic Refinement (CSR) and Cross-modal Spectral Alignment (CSA). Specifically, CSR first adaptively extracts visual and acoustic representations by corresponding adapters to form a unified multimodal prefix with language in the frozen LLM embedding space. It then iteratively produces continuous discriminative semantic states through a token-efficient latent refinement process without decoding explicit text. Next, CSA simultaneously aligns the refined semantics with all modalities by enhancing the dominant spectral component of their kernel Gram matrix. This captures global nonlinear dependencies among all representations without relying on a predefined anchor modality. In addition, an instance-level spectral separation constraint preserves cross-sample discriminability and mitigates representation collapse. Extensive experiments on SIMS, MOSI, and MOSEI benchmarks demonstrate that SemMSA achieves state-of-the-art performance.

- **研究背景**：多模态情感分析（MSA）旨在融合语言、视觉、声学三种模态推断人类情感。现实场景中，由于噪声、遮挡、传感器故障或传输不稳定，多模态观测常不完整，其中**模态内缺失**（每个模态内部部分 token、帧或声学片段损坏）尤为常见，会显著降低在完整数据假设下训练的模型性能。
- **现有方法的不足**：
  - **重建式方法**：从部分观测中恢复完整特征，但倾向于重建低层特征模式而非高层语义；同一文本可能对应多种合理的语音韵律和面部表情，易产生与真实情感证据相矛盾的"幻觉特征"。
  - **融合式方法**：通过复杂跨模态交互直接整合可用模态，但在严重缺失下会过拟合训练时观察到的模态共现模式，导致不稳定引导与判别性退化。
- **核心动机**：人类情感理解依赖可靠上下文线索与情感表达先验知识，这启发**语义级补偿**——用丰富的情感相关语义信息充实不完整的表征。LLM 具备强大的上下文表示与语义抽象能力，但直接解码文本描述会带来昂贵开销，因此需要一种在隐藏空间中高效利用 LLM 语义的机制。
- **整体含义**：论文提出 **SemMSA**，首次尝试利用 LLM 进行语义级补偿的 MSA 框架，通过潜在语义辅助与无锚点谱对齐，在模态不完整条件下实现鲁棒的情感推断。

## 2. 论文提出的方法论

### 核心思想
利用冻结 LLM 构建情感相关的连续潜在语义状态，并通过**无锚点谱对齐**将语义与语言、视觉、声学四种表征同时对齐，避免锚模态依赖与显式文本解码的开销。

### 关键技术细节

- **多模态输入预处理**：
  - 每个模态 $U_m$（$m \in \{v,a,l\}$）先由冻结的模态特定编码器 $f_\phi$ 处理，得到序列表示 $X_m \in \mathbb{R}^{T_m \times d_m}$。
  - 语言用 BERT 编码，音频用 Librosa 提取，视觉用 OpenFace 提取。

- **跨模态语义精炼（CSR）**：
  - **视觉/音频适配器**：使用 $M$ 个可学习提示嵌入 $P_m$，经 $B$ 个轻量 Transformer 块，通过交叉注意力从 $X_m$ 中提取模态证据、自注意力捕获模态内依赖，再线性投影到 LLM 维度，得到 $Z_v, Z_a \in \mathbb{R}^{M \times d}$。
  - **多模态前缀构建**：$U^{(0)} = [Z_l; Z_v; Z_a] \in \mathbb{R}^{(T+2M) \times d}$，作为冻结 LLM 的初始输入。
  - **迭代隐藏状态精炼**：将 LLM 最后位置隐藏状态 $z_k = f(U^{(k-1)})$ 作为连续潜在 token 追加到前缀中，$U^{(k)} = [U^{(k-1)}; z_k]$，重复 $O$ 步，得到语义状态序列 $Z = [z_1; \dots; z_O]$。
  - **语义表征**：$H_s = W_s \cdot \text{Pool}(Z) + b_s$。
  - 该过程**不做自回归文本解码**，仅在连续隐藏空间迭代精炼，token 效率高。

- **跨模态谱对齐（CSA）**：
  - 将四种归一化表征 $V = (h_s, h_v, h_a, h_l)$ 构建线性 Gram 矩阵 $G = V^\top V$。
  - 扩展到 RKHS，使用 RBF 核 $\kappa(h_i,h_j)=\exp(-\|h_i-h_j\|_2^2 / 2\sigma^2)$，构建核 Gram 矩阵 $K$。
  - 对 $K$ 做特征分解 $K = Q\Lambda Q^\top$，$\lambda_1 \ge \lambda_2 \ge \lambda_3 \ge \lambda_4 \ge 0$。若四表征完全对齐，$K$ 退化为秩一矩阵。
  - **谱对齐损失**：将特征值视为 logits，用 softmax 增强 $\lambda_1$ 的主导性：
    $$\mathcal{L}_{csa} = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp(\lambda_1^i/\tau)}{\sum_{j=1}^{4}\exp(\lambda_j^i/\tau)}$$
  - **实例级谱分离约束**：将主导特征向量 $q_1^i$ 投影回表征空间得到主导语义方向 $u_1^i = \frac{V_i q_1^i}{\|V_i q_1^i\|_2}$，惩罚不同实例主导方向的高相似度：
    $$\mathcal{L}_{sep} = \frac{1}{N(N-1)}\sum_{i=1}^{N}\sum_{j\neq i}\left[(u_1^i)^\top u_1^j\right]^2$$

- **融合与预测**：$\hat{H} = H_s + H_v + H_a + H_l$，送入线性分类器得预测 $\hat{y}$。
- **总损失**：$\mathcal{L}_{total} = \frac{1}{N}\sum_i \|y_i - \hat{y}_i\|_2^2 + \mathcal{L}_{csa} + \mathcal{L}_{sep}$。

### 理论支撑
- **引理 1**：RKHS 中模态完全对齐 $\Leftrightarrow$ 核 Gram 矩阵秩一（$K = \mathbf{1}\mathbf{1}^\top$）。
- **定理 1**：$K$ 秩一 $\Leftrightarrow$ $\lambda_1 = k, \lambda_2 = \cdots = \lambda_k = 0$；增强 $\lambda_1$ 主导性等价于降低残差谱能量 $k - \lambda_1$，推动 $K$ 趋近秩一。
- **无锚点特性**：主导特征向量 $q_1$ 由所有模态的联合谱结构决定，不依赖任何预定义锚模态。

## 6. 论文的主要结论与发现

- **SOTA 性能**：SemMSA 在 SIMS、MOSI、MOSEI 三个基准上，在多种缺失设置下均取得最优或极具竞争力的结果，平均准确率提升约 **1.4%**。
- **模态内缺失**：
  - MOSI：Acc-5 和 Acc-7 较最佳基线 TF-Mamba 分别提升 **2.43%** 和 **2.23%**，MAE 降至 **1.011**。
  - MOSEI：Acc-2 达 **79.61**，F1 达 **80.62**。
  - SIMS：Corr 较 P-RMF 提升 **0.087**。
  - 随缺失率上升，多数基线明显退化，SemMSA 保持更稳定性能。
- **模态间缺失**：MOSEI 上平均 F1 达 **77.89**，较次优 CorrKD 提升 **2.71%**；语言缺失场景（{a,v}）提升显著，表明语义精炼能有效利用非语言证据。
- **完整模态**：MOSI 达 88.70 Acc-2、88.56 F1、50.97 Acc-7、0.861 Corr、0.628 MAE；MOSEI 达 88.88 Acc-2、87.70 F1、55.90 Acc-7、0.877 Corr、0.513 MAE。
- **消融结论**：CSR 单独引入即显著提升（平均 Acc-2 +5.68%、F1 +11.11%）；$\mathcal{L}_{csa}$ 进一步提升跨模态一致性；$\mathcal{L}_{sep}$ 最终带来最佳性能，三者互补。
- **精炼步数**：$O=4$ 为最佳平衡点，$O$ 过大（5、6）会引入冗余噪声并增加计算成本。
- **LLM 角色**：LLM 作为**语义生成器**显著优于直接预测器；不同 LLM（Qwen3-1.7B/8B、Llama3.1-8B、Qwen2.5-Omni-7B）下 SemMSA 均鲁棒。
- **效率**：较 LNLN 减少 50.5% 任务 GFLOPs，较 P-RMF 减少 54.3% 推理时间，同时性能更优。

## 7. 优点

- **方法创新性**：
  - **首次**将 LLM 用于 MSA 的语义级补偿，而非直接预测或文本解码。
  - **无锚点谱对齐**：通过核 Gram 矩阵主导谱分量实现 any-to-any 对齐，避免锚模态依赖，在严重缺失下更稳定。
  - **token 高效的潜在精炼**：在隐藏空间迭代生成语义状态，避免自回归解码开销，适配器仅 4.7M 参数。
  - **实例级谱分离约束**：有效缓解表示坍缩，保持跨样本判别性。
- **理论支撑**：附录提供完整理论分析（引理 1、定理 1），证明主导谱分量增强与 RKHS 完全对齐的等价关系，以及无锚点性质。
- **实验设计亮点**：
  - 同时覆盖模态内与模态间两种缺失范式。
  - 逐缺失率（0-0.9）细粒度对比，揭示鲁棒性趋势。
  - 多维对比（投影、对齐、LLM、精炼步数、效率），验证各设计选择。
  - 案例研究与混淆矩阵可视化，直观展示方法在极端缺失下的优势。
- **效率优势**：在性能提升的同时显著降低 GFLOPs 与推理延迟，实用性较强。

## 8. 不足与局限

- **数据集覆盖有限**：实验仅基于

MOSI、MOSEI 和 SIMS 三个基准数据集，均以视频-文本-音频三模态情感回归/分类为主。虽然覆盖中英文，但样本规模、领域和文化背景仍有限，未涉及更多真实场景（如在线会议、医疗问诊、人机交互、短视频直播等），也未覆盖情绪识别、讽刺检测、幽默识别、人格分析等相关任务，因此方法泛化性仍需更广泛验证。

- **缺失假设较理想化**：实验主要采用随机实例级掩码或整模态移除，未充分评估结构化缺失、非随机缺失、模态相关缺失、连续片段丢失、传感器漂移或标注噪声等更复杂情形。真实场景中缺失往往与情感内容本身相关（如说话人情绪激动时语音中断），随机缺失假设可能高估方法鲁棒性。
- **训练仍依赖完整模态监督**：尽管推理阶段可处理不完整输入，但训练时保留 50% 完整样本，并需要完整多模态数据来学习语义精炼与谱对齐。若某些模态在训练集中长期缺失，或完整模态配对数据稀缺，方法能否维持优势尚不明确。
- **LLM 使用方式与规模边界**：默认采用冻结 Qwen3-1.7B，虽对比了 Qwen3-8B、Llama3.1-8B、Qwen2.5-Omni-7B 等，但未系统探索更大规模、闭源模型或领域专用模型的上限与边际收益；同时，LLM 的语义先验可能引入预训练数据偏见，论文未分析情感表达中的性别、文化、地域偏差。
- **潜在语义状态可解释性不足**：迭代隐藏状态精炼生成的是连续潜在 token，缺少对语义内容、情感极性、模态贡献的显式解释。案例研究虽提供直观示例，但无法保证潜在语义始终对应可靠情感证据，仍可能存在“语义幻觉”风险。
- **超参数与理论假设限制**：谱对齐依赖 RBF 核带宽 $\sigma$、温度 $\tau$、精炼步数 $O$、提示数量 $M$ 等超参数；理论分析建立在 RKHS 与核 Gram 矩阵秩一假设上，实际中完全对齐难以严格满足。不同模态特征分布差异较大时，核函数选择与尺度归一化可能影响稳定性。
- **实验评估仍有空白**：
  - 模态间缺失实验主要在 MOSEI 上开展，未在 MOSI、SIMS 上系统验证。
  - 极端缺失率（如 $r=0.8,0.9$）下 SemMSA 并非所有指标均最优，部分指标被 TF-Mamba 等基线超越，论文对失败案例与边界条件讨论较少。
  - 未报告统计显著性检验、置信区间或效应量，难以判断性能提升是否稳定显著。
  - 缺少对推理阶段真实缺失模式、在线流式缺失、缺失率动态变化等部署场景的评估。
- **效率与资源报告不完整**：论文给出了 GFLOPs、内存和延迟，但未明确 GPU 数量、总训练时长、能耗与碳排放；适配器参数虽少，但冻结 LLM 的前向计算仍带来较高显存与推理成本，在边缘设备或低资源场景中的可行性有限。
- **可复现性与工程细节**：未明确说明是否公开代码、数据预处理细节、缺失掩码生成种子、基线复现方式等；不同 LLM、编码器版本和硬件环境可能导致结果波动，影响复现一致性。
- **伦理与隐私考量不足**：多模态情感分析涉及语音、面部图像和文本等敏感数据，论文未讨论数据授权、隐私保护、模型偏见缓解、误用风险及伦理审查，实际部署时需补充相应规范。

## 9. 总体评价与启示

SemMSA 的核心贡献在于将 LLM 从“直接预测器”或“文本生成器”转变为“潜在语义补偿器”，并通过无锚点谱对齐实现语言、视觉、声学与语义四种表征的联合一致性约束。这一思路在模态不完整条件下具有较强启发性：一方面避免了重建式方法易产生低层幻觉的问题，另一方面绕开了自回归文本解码的高开销。方法在 MOSI、MOSEI、SIMS 上取得了有竞争力的结果，消融与对比实验也较充分地支撑了各组件有效性。

然而，论文仍属于“在受控缺失设定下验证语义补偿潜力”的研究，距离真实复杂场景部署还有距离。未来工作可重点关注：非随机与结构化缺失下的鲁棒性、训练阶段模态不完整时的学习机制、潜在语义的可解释性与偏见控制、更大规模与多语言多文化验证，以及更完整的效率、统计显著性与伦理评估。
