## 摘要
近年来，多模态持续学习通过跨多种模态持续学习新任务，在开发具有类人智能的智能体方面展现出巨大潜力。然而，现有方法通常假设每个任务的模态集合是预先定义且固定的。在本文中，我们研究了一种更为现实的学习设置，称为动态多模态持续学习，其中模态集合可随任务变化而改变，而非固定不变。该设置面临两大主要挑战：（i）时空灾难性遗忘和（ii）自适应多模态融合。为解决这些问题，我们提出了NeuCME（Neural Combinatorics of Multiple Experts，即多专家神经组合），该框架旨在有效学习和整合不同模态任务间的知识。所提出的NeuCME模型包含三个关键组成部分：模态组合回放、多门控混合专家和任务相关性引导蒸馏。此外，我们制定了一个评估指标以量化任务序列的动态程度，并构建了一个涵盖不同动态程度的综合基准。基于四个真实数据集的大量实验表明，所提出的NeuCME在性能上显著优于现有最先进方法。

## Abstract
Multimodal continual learning has recently shown great potential for developing agents with human-like intelligence by continuously learning new tasks across multiple modalities. However, existing methods typically assume that the set of modalities per task is predefined and fixed. In this paper, we investigate a more realistic learning setting, referred to as dynamic multimodal continual learning, in which the set of modalities may vary across tasks rather than remaining fixed. This setting involves two primary challenges: (i) spatio-temporal catastrophic forgetting and (ii) adaptive multimodal fusion. To address these challenges, we propose NeuCME (as shorthand for \textbf{Neu}ral \textbf{C}ombinatorics of \textbf{M}ultiple \textbf{E}xperts), a novel framework designed to effectively learn and integrate knowledge across tasks with varying modalities. The proposed NeuCME model comprises three key components, namely modality-combinational rehearsal, multi-gated mixture-of-experts, and task relevance-guided distillation. Furthermore, we formulate an evaluation metric to quantify the dynamism of task sequences and then set up a comprehensive benchmark with different degrees of dynamism. Extensive experiments using four real-world datasets demonstrate that the proposed NeuCME outperforms state-of-the-art methods markedly.

## 1. 核心问题与研究动机

- 论文提出并研究一个新问题：**动态多模态持续学习（Dynamic Multimodal Continual Learning, Dynamic MCL）**。与传统的多模态持续学习（MCL）不同，该问题允许每个任务所包含的模态集合不同，即模态集合可随任务流动态变化，更贴近真实场景（例如传感器失效导致模态缺失、新需求引入新模态）。
- 任务间的模态变化被归纳为三类：**模态增强任务**（新增模态）、**模态减少任务**（移除模态）、**模态混合任务**（同时发生增删）。
- 这一设定带来的新挑战包括：
  - **空间灾难性遗忘**：模态空间变化（新模态加入或旧模态缺失）导致跨模态知识干扰和遗忘；
  - **时间灾难性遗忘**：随时间推移新任务覆盖旧知识，且在模态动态变化下被进一步放大；
  - **自适应多模态融合**：现有方法依赖固定模态组合下的预定义融合规则（如拼接、注意力），无法处理模态数量与类型动态变化的输入。
- 作者认为这一问题尚未被系统研究，现有MCL基本都假设固定模态集，因此需要新的方法框架。

## 2. 方法论（NeuCME）

- **核心思想**：利用多专家模型与任务级适配器，在共享单模态编码器的基础上，对各任务的模态子集进行组合式训练，结合门控聚合与相关性引导的蒸馏，以实现对动态模态序列的持续学习。
- 方法整体包含三个协同组件：

### 2.1 模态组合回放（Modality-Combinational Rehearsal）
- 观察到不同任务的模态集合常呈现子集-超集关系（subset-superset），因此不应为每个任务训练独立模型，而是共享每个模态的编码器。
- 训练时，在当前任务模态集合 \(M_t\) 的基础上，优化所有非空子组合 \(S \subseteq M_t\) 的损失：
  \[
  \arg\min_\theta \; \mathbb{E}_{S \sim P(M_t)\setminus \emptyset}\left[\mathcal{L}(f_\theta(\{x_i^t\}_{i\in S}); y_t)\right]
  \]
- 这一策略使模型只需在所有任务间共享最多 \(\max |M_t|\) 个单模态编码器，而不是为每个任务单独训练 \(|M_t|\) 个编码器，避免了参数爆炸，同时增强了模态不变表示和泛化能力。
- 每个梯度步同时用当前完整模态和随机/遍历子组合更新模型，使模型学会处理不同模态缺失的组合。

### 2.2 多门控混合专家（Multi-gated Mixture-of-Experts, MMoE）
- 结构：共享路由器 \(R\)、若干专家 \(\{E_i\}\)、每个任务拥有可扩展的门控网络 \(G_t\)。
- 处理流程：
  1. 各模态编码器提取表示 \(r_i^t\)；
  2. 路由器 \(R\) 为每个模态表示分配一个最相关专家：\(N_i = \text{TopOne}(R(r_i^t))\)；
  3. 任务 \(t\) 的门控网络 \(G_t\) 根据当前模态集合生成门控权重：
     \[
     W^t = \text{Softmax}(G_t(\text{concat}[r_i^t]_{i \in M_t}))
     \]
  4. 聚合专家输出得到联合表示：
     \[
     h^t = \sum_{i \in M_t} W_i^t e_i^t
     \]
- 创新点：将常规MoE中的“路由”和“融合”进行解耦，路由网络负责稀疏选择专家，门控网络负责聚合不同模态的专家输出，以兼容不同数量的多模态输入。

### 2.3 任务相关性引导蒸馏（Task Relevance-guided Distillation）
- 在当前任务 \(t\) 学习得到联合表示 \(h_t\) 后，采用任务级适配器 \(Adapter_t\) 生成任务表示 \(z_t\)，并通过全连接层预测。
- 为了缓解时间灾难性遗忘，引入知识蒸馏；
- **教师选择机制**：为每个任务适配器训练轻量级自编码器，自编码器的重构误差 \(re_t = \|h_t - h_t^o\|_2\) 用于衡量当前数据与历史任务的相似性。
- 蒸馏目标为：
  \[
  \mathcal{L}_{\text{distill}} = \text{MSE}\left(z_t, \sum_{i=1}^{t-1} W_i^t \, Adapter_i(h_t)\right)
  \]
  权重 \(W^t\) 通过 softmax 归一化 top-\(k\) 最低重构误差来计算，即只从最相关的 \(k\) 个历史适配器进行知识转移。
- 该策略可避免引入不相关历史任务带来的负面干扰，同时相比数据回放更节省存储并保护隐私。

### 2.4 总损失
\[
\mathcal{L}_{\text{NeuCME}} = \mathcal{L}_{\text{task}} + \mathcal{L}_{\text{recon}} + \mathcal{L}_{\text{distill}}
\]

## 3. 实验设计

### 3.1 Benchmark 与动态程度指标
- 现有数据集无法直接用于动态MCL，作者基于四个公开多模态数据集构造了动态任务序列：
  - **CUBICC**（图像-文本）
  - **IEMOCAP**（视频-文本-音频情感识别）
  - **MMEA-CL**（连续场景下的多模态自我中心行为识别，含视频/音频/惯性G等）
  - **CMU-MOSEI**（真实情境多模态情感分析）
- 提供新的动态程度度量：
  \[
  D_{\text{metric}} = \frac{1}{N-1}\sum_{i=1}^{N-1}\left(1 - \frac{|M_i \cap M_{i+1}|}{|M_i \cup M_{i+1}|}\right)
  \]

## 6. 主要结论与发现

- NeuCME 在几乎所有动态程度设置上优于现有方法，尤其在动态程度较高的L4与UB下优势明显；
- 单模态持续学习方法往往弱于多模态方法，说明利用多模态互补信息对动态MCL至关重要；
- 模态混合任务比增强/减少任务难度更大，而NeuCME在此类任务上取得更显著的优势，说明其学到更鲁棒的模态不变表示；
- 三个组件均有效，但各自贡献随数据类型存在差异：
  - 在原始数据（CUBICC、MMEA-CL）上，模态组合回放的贡献最大；
  - 在预提取特征数据（IEMOCAP、CMU-MOSEI）上，多门控MoE贡献最大；
- 适度数量的专家（一般10个）效果最好，过多专家会导致冗余和不均衡；
- top-k 取值需要配合任务序列长度：短序列使用较小k（如1），较长序列中等k（如3）最合适；
- 多门控优于单门控，top-k蒸馏优于全部/前一任务/随机蒸馏。
