## 摘要
情绪偏好学习利用候选描述之间的成对比较，使多模态大语言模型（MLLMs）与人类对开放式情绪描述的判断保持一致，并训练能够捕捉人类情绪偏好的奖励模型。然而，传统的成对监督通常较为稀疏，通常仅为每个正面描述提供一个负面描述，因此对情绪描述可能出错的各种方式的覆盖有限。特别是，模型可能对语义流畅但情绪不一致的描述缺乏足够的暴露。除了这一数据层面的局限外，依赖单一的MLLM评判者还引入了独特的模型层面问题：在解释细粒度或模糊的多模态情绪线索时，其判断可能受到模型特定偏差的影响。为解决这些局限，我们提出了误差增强偏好优化（EAPO），一个在数据和模型两个层面提升基于MLLM的情绪偏好判断可靠性的框架。首先，我们通过从每个偏好描述中生成多个受控且情绪感知的负面描述来构建误差增强数据集。然后，我们使多个独立的MLLM评判者适应这种更丰富的监督，并使用边际校准软融合来聚合它们的偏好边际，该融合在聚合前将异构边际映射到共同尺度。在MER2026-EmoPrefer挑战赛数据集和我们的误差增强数据集上的实验表明，EAPO在评估与视频多模态情绪证据相冲突的流畅描述时，提升了情绪偏好预测能力，并增强了MLLM评判者的鲁棒性。我们的代码可在 https://github.com/slash1028/EAPO-EmoPrefer 获取。

## Abstract
Emotion preference learning uses pairwise comparisons between candidate descriptions to align multimodal large language models (MLLMs) with human judgments of open-ended emotion descriptions and to train reward models that capture human emotional preferences. However, conventional pairwise supervision is often sparse, typically providing only a single negative description for each positive description, and therefore offers limited coverage of the diverse ways in which an emotion description can be incorrect. In particular, models may be insufficiently exposed to semantically fluent but emotionally inconsistent descriptions. Beyond this data-level limitation, relying on a single MLLM judge introduces a distinct model-level concern: its judgments can be affected by model-specific biases when interpreting fine-grained or ambiguous multimodal emotional cues. To address these limitations, we propose Error-Augmented Preference Optimization (EAPO), a framework for improving the reliability of MLLM-based emotion preference judgment at both the data and model levels. First, we construct an error-augmented dataset by generating multiple controlled and emotion-aware negative descriptions from each preferred description. We then adapt multiple independent MLLM judges to this richer supervision and aggregate their preference margins using margin-calibrated soft fusion, which maps heterogeneous margins to a common scale before aggregation. Experiments on the MER2026-EmoPrefer Challenge dataset and our error-augmented dataset demonstrate that EAPO improves emotion preference prediction and enhances the robustness of MLLM judges when evaluating fluent descriptions that conflict with the video's multimodal emotional evidence. Our code is available at https://github.com/slash1028/EAPO-EmoPrefer.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：情绪偏好学习（Emotion Preference Learning）通过成对比较候选情绪描述，使多模态大语言模型（MLLMs）与人类对开放式情绪描述的判断对齐，并用于训练奖励模型。
- **数据层面问题**：传统成对监督非常稀疏——每个正向描述通常只配一个天然的负向描述，导致模型对"语义流畅但情绪不一致"的描述缺乏充分暴露。具体而言，模型难以覆盖多种错误模式，如情绪翻转（Emotion Flip）、强度不匹配（Intensity Mismatch）、证据矛盾（Evidence Contradiction）、模态遗漏（Modality Omission）等。
- **模型层面问题**：依赖单一 MLLM 评判器存在模型特定偏差，尤其是在解释细粒度或模糊的多模态情绪线索时，评判结果可能不稳定或带有偏见。
- **核心意义**：该论文旨在同时从**数据级**和**模型级**两个层面提升 MLLM 情绪偏好判断的可靠性，不仅提高与人类偏好的一致性，还增强对"流畅但情绪错误"描述的鲁棒性。

## 2. 方法论

### 2.1 整体框架（EAPO）
EAPO（Error-Augmented Preference Optimization）包含两大核心组件：
- **数据级增强**：误差增强的负样本构造（Error-Augmented Negative Construction）
- **模型级增强**：边际校准的多评判器软融合（Margin-Calibrated Multi-Judge Fusion）

### 2.2 误差增强负样本构造

- 以人类标注的偏好正样本 $d^+$ 为锚点，**保留原始人类标注的拒绝描述（Original Rejected）** 作为自然负样本。
- 额外生成四类受控合成错误类型：

| 错误类型 | 定义 |
|---|---|
| Emotion Flip | 将推断的情感替换为不同或相反的情绪 |
| Intensity Mismatch | 保留情感但夸大或减弱其强度 |
| Evidence Contradiction | 引入与可观察多模态证据直接矛盾的描述 |
| Modality Omission | 删除来自某一模态的自我包含证据片段，保留其余内容 |

- 构造流程（以 Emotion Flip 为例）：
  1. 将偏好描述按句切分；
  2. 使用文本版 Qwen3-30B-A3B-Instruct 作为"编辑规划器"（Edit Planner LLM），对每种错误类型分别调用，生成结构化编辑计划（目标句、源片段、修改方案）；
  3. **确定性编辑应用**：只修改指定片段，不重写全文；
  4. **自动规则校验**：检查结构有效性、编辑局部性、未预期改动/重复；
  5. **独立语义验证**：使用同一文本模型作为语义验证器，检查错误类型匹配、非目标内容保留、流畅性；
  6. 只保留全部校验通过的样本，并采用候选顺序交换存储以缓解位置偏差。

### 2.3 轻量 SFT-to-DPO 评判器适配

- 每个 MLLM 评判器独立依次经历两个阶段：
  1. **LoRA 监督微调（SFT）**：使用标准语言建模损失 $L_{SFT}$，学习二选一比较格式与任务偏好标准；
  2. **直接偏好优化（DPO）**：从 SFT 检查点初始化，使用标准 DPO 损失 $L_{DPO}$ 增大正标签相对负标签的似然。
- 训练数据包括原始偏好对 + 四类受控错误增强对，并进行候选顺序交换以降低位置偏差。
- LoRA 仅更新少量参数，允许多个评判器独立低成本适配。

### 2.4 边际校准的多评判器融合

- 对每个评判器 $j$，定义**有符号偏好边际（signed preference margin）**：

$$m_j(q) = \ell_j(a_2|q) - \ell_j(a_1|q)$$

其中 $\ell_j(a_r|q)$ 为评判器对答案标签 $a_r$ 的负对数似然；$m_j > 0$ 表示偏好 $d_1$，$m_j < 0$ 表示偏好 $d_2$。

- **边际校准**（Marginal Calibration）：各评判器的原始边际尺度不同，直接平均不可靠，因此按标准差归一化：

$$\tilde{m}_j(q) = \frac{m_j(q)}{\sigma_j + \epsilon}$$

其中 $\sigma_j$ 为评判器 $j$ 在评估集上全部原始边际的标准差（无需偏好标签即可计算），$\epsilon = 10^{-6}$。

- **软融合**（Soft Fusion）：将归一化后的边际等权平均：

$$m_{fuse}(q) = \frac{1}{3} \sum_{j=1}^3 \tilde{m}_j(q)$$

- 最终预测由融合边际的符号决定。与硬投票相比，该方法保留了偏好的**分级强度信息**。

## 6. 主要结论与发现

1. **误差增强训练的效果显著**：仅用原始偏好对训练（Normal SFT）可能导致模型过拟合到原分布（提升 Original Val 但降低 4-Error Avg），而加入生成错误对后，Error-Aug SFT+DPO 在三项指标上均达到最优，说明合成的受控错误能帮助模型区分"有依据的描述"与"流畅但有误导性的描述"。
2. **融合优于单一评判器**：边际校准软融合（EAPO）在 Original Val 上达到 80.31% WAF（单一最优为 79.04%），在官方 Macro WAF 上达 80.23%，优于所有单评判器（最优 79.40%）及硬投票（78.47%）和原始平均融合（79.31%）。
3. **校准是融合的关键**：直接对原始边际取平均不如先归一化再融合，说明不同评判器的边际尺度确实存在较大差异，跨评判器校准是有效融合的必要步骤。
4. **互补性驱动收益**：不同模型具有互补优势——Qwen3 在原始验证集最优，MiniCPM 在生成错误鲁棒性和顺序一致性上更强——融合的收益来自这种互补性而非单个主导模型。
5. **官方排名**：提交在 MER2026-EmoPrefer 排行榜上排名第六，并超越所有官方基线（包括此前最强的 Qwen2.5-Omni Zero-shot 78.74%）。

## 7. 优点与亮点

- **数据层面的创新**：通过"编辑规划 → 确定性应用 → 规则校验 → 语义验证"的流水线，生成高质量、局部化的受控错误样本，避免了无约束 LLM 改写可能引入的无关改动（学习捷径）。对每种错误类型使用独立调用，防止错误类型混合，控制力强。
- **模型层面的创新**：提出了"边际校准软融合"，将多个独立 MLLM 评判器的偏好边际标准化后再等权融合，既避免了硬投票丢弃分级强度信息的问题，又解决了直接平均不可比的问题。该方法不需要偏好标签，仅依赖边际自身分布统计，实现简单且有效。
- **多评判器独立适配**：每个评判器独立训练、互不通信，保留了模型的多样性，融合时才能形成互补。
- **实验设计较为完整**：从原始验证到生成错误子集再到官方测试两阶段，从单评判器到融合方法，逐步消融验证了各组件（误差增强数据、DPO、候选顺序交换、校准）的贡献。
- **代码开源**，有助于复现与后续研究。

## 8. 不足与局限

### 8.1 数据层面的局限
- 误差增强对的构造依赖 LLM 生成（Qwen3-30B-A3B-Instruct），生成质量可能随样本不同而波动；
- 尽管有验证机制，但无法完全保证每对生成的错误类型精确对应且没有引入隐式改动；
- 人为设计的四类错误可能并未覆盖所有真实世界错误模式。

### 8.2 推理策略层面的局限
- S2 策略依赖中间视频描述的质量：如果生成的描述遗漏关键信息或包含错误线索，会传播到最终判断。文中也承认了这一局限。

### 8.3 实验与评估层面的局限
- 计算资源信息缺失：没有报告 GPU 型号、数量、训练时长，影响复现与成本评估；
- 融合方法仅在同源数据分布上验证，当模型替换或域迁移时稳定性未知；
- 缺乏统计显著性检验，无法确认观测到的性能提升是否在统计上稳健；
- S1/S2 策略未在所有模型中统一使用，间接影响模型间公平比较。

### 8.4 潜在偏差风险
- 验证集中的生成错误子集与训练集使用同一构造流程，属于同分布评估，可能高估模型对错误类型的敏感性；
- 官方排行榜结果虽然被引用，但报告与验证集表现的不一致性（如 MiniCPM 在官方测试上零样本反而更好）说明不同阶段的分布差异较大，模型的泛化稳定性需更多研究。
