## 摘要
多模态图像融合（MMIF）旨在将互补的传感器数据集成到单一表示中，在保留场景内在真实性的同时消除环境干扰。大多数现有方法依赖盲特征聚合，这擅长信号累积，但无法区分本质内容与物理退化。我们提出SGPDFuse，通过基于预训练视觉基础模型构建的语义-物理参数桥（SPPB）将输入映射为物理解缠的结构表示，利用内在-变化原理将不变的场景属性与瞬态环境因素解耦，从而弥合这一差距。为引导这种分解，我们引入了一种语义对齐机制：通过余弦相似度将融合表示显式锚定到同一基础模型特征空间中的显著语义特征上，以保留关键目标；同时通过Gram矩阵正则化强制物理纹理保真度，严格消除不自然伪影。大量实验表明，SGPDFuse使用单一架构在红外-可见光、多聚焦和多曝光基准上均实现了最先进的性能。

## Abstract
Multimodal image fusion (MMIF) aims to integrate complementary sensor data into a single representation that preserves intrinsic scene reality while eliminating environmental interferences. Most existing approaches rely on blind feature aggregation, which excels at signal accumulation but fails to distinguish essential content from physical degradations. We propose SGPDFuse, which bridges this gap by mapping inputs into a physics-disentangled structural representation via a Semantic-Physical Parametric Bridge (SPPB) built on pretrained vision foundation models, utilizing the Intrinsic-Variation principle to decouple invariant scene attributes from transient environmental factors. To guide this decomposition, we introduce a Semantic Alignment mechanism: we explicitly anchor the fused representation to salient semantic features in the same foundation model feature space via cosine similarity to preserve critical targets, while enforcing physical texture fidelity through Gram-matrix regularization to strictly eliminate unnatural artifacts. Extensive experiments demonstrate that SGPDFuse achieves state-of-the-art performance across infrared-visible, multi-focus, and multi-exposure benchmarks using a single architecture.

- **研究背景**：多模态图像融合（MMIF）旨在将不同传感器采集的互补信息（如红外热辐射与可见光纹理、多曝光亮度、多焦点清晰度）整合为一张高质量图像，同时保留场景的内在真实内容并抑制环境干扰。融合结果通常还作为目标检测、语义分割等下游感知任务的输入，其质量直接影响后续系统的鲁棒性。
- **核心问题**：现有深度融合方法大多将融合视为“信号聚合”问题，即通过加权求和或特征拼接来最大化信息保留。论文指出这种范式存在根本性缺陷——它把两类本质不同的信号成分混为一谈：
  - **内在（Intrinsic）成分**：场景固有的物理属性（真实温度、表面反射率、清晰纹理等），是任何高质量融合都必须保留的部分；
  - **变化（Variation）成分**：由环境或传感器引入的瞬态干扰因素（热反射、光照变化、光学模糊等），是融合中应当抑制的部分。
- **导致的现象**：这种混淆会产生持续的伪影，如反射表面上的“幽灵”热目标、曝光失衡引起的色偏、离焦区域的纹理丢失等。作者用数学证明（式 2）说明：只要在分离 Φ 与 Ψ 之前直接融合纠缠信号，变化残差 Ψ̂ 在存在变化的每个像素上严格为正，任何加权策略都无法消除伪影。
- **研究意义**：本文提出以“物理解缠”视角重新审视融合目标，将融合从盲特征聚合转变为“先解耦、再融合”，为多模态融合提供了一种统一且可解释的新范式。

## 2. 论文提出的方法论

### 2.1 核心思想

论文提出 **SGPDFuse**，核心洞察是：红外成像、Retinex 理论、散焦模型等不同物理成像过程共享统一结构 **I = G(Intrinsic, Variation)**。基于此，融合不应盲目聚合信号，而应先解耦内在内容与变化因素，再仅对内在成分进行融合。

### 2.2 关键技术细节

**(1) 统一的潜在因子成像模型（式 1）**

每个模态的观测图像被建模为两个潜在因子的组合：Φ（内在分量，模态不变、场景特有）与 Ψ（变化分量，环境/传感器诱导）。Φ 和 Ψ 都是潜在不可直接观测的。

**(2) 尺度对齐分解（式 3）**

将 Intrinsic-Variation 分解与 Base（低频）-Detail（高频）信号分解相结合，形成两轴分解，得到四阶段流程：
- 将每个源图像分解为 base/detail；
- 通过语义桥估计变化置信图 W；
- 在每个尺度上解缠 Φ 与 Ψ；
- 仅融合 {Φ_b, Φ_d}，从构造上消除变化。

**(3) 网络架构（如图 3）**

- **双分支统一编码器**：采用 NAFNet 块提取 base（低频频带）和 detail（高频频带）特征，通道数 d=64。DINOv3 语义 token 通过交叉注意力注入 detail 分支（after 第二个 NAFNet 块），为高频特征提供语义基础；base 分支保持纯卷积。
- **语义-物理参数桥（SPPB）**：使用 LoRA 微调的 DINOv3（ViT-S/16）提取空间语义 token，通过软最近邻回归（soft nearest-neighbor regression）从“物质库”中检索逐像素物理参数锚点（如发射率 ε、曝光最优性、聚焦概率），再与编码器特征结合预测变化置信图 W。物质库由任务特定的物理测量值与 DINOv3 原型嵌入构成。
- **内在-变化解缠**：用 W 加权投影分离 Φ 与 Ψ：

  F_Φ = W ⊙ F + R_Φ(W ⊙ F)；
  F_Ψ = (1−W) ⊙ F + R_Ψ((1−W) ⊙ F)。

  引入可学习残差网络 R_Φ、R_Ψ 修正两分量的非正交性，并通过结构一致性约束 F_Φ + F_Ψ ≈ F 防止信息丢失或重复。互补源分配设定 W_A = W、W_B = 1−W，编码物理互补性（如发射率-反射率对偶）。在 base 和 detail 两个尺度上，Ψ 分量在融合前被直接丢弃。
- **物理引导融合**：base 层使用 SE 通道注意力（由 W 偏置的置信度加权）；detail 层使用 ℓ1 范数活动度加权选择更清晰模态。
- **损失函数**：
  - 阶段 1（重构预训练）：ℓ1 + SSIM 损失；
  - 阶段 2（端到端融合）：L_total = L_IG + λ_decomp·L_decomp + λ_RecA·L_RecA + λ_tv·L_tv，其中 L_IG 为强度-梯度保真损失（对源图像最大值约束），L_decomp 为分解损失（含交叉相关与一致性约束），L_RecA 为重构对齐损失（DINOv3 特征空间的余弦内容对齐 + Gram 矩阵风格正则化），L_tv 为变化图的总变差平滑正则。

## 8. 缺点与局限性

- **效率与实用性未验证**：模型引入 DINOv3（ViT-S/16）+ LoRA + SPPB + 双分支 NAFNet 编码器，结构较重；论文未报告参数量、FLOPs、单帧推理时间等关键效率指标，也未与轻量级方法对比。对于实时性要求较高的下游系统（如自动驾驶、无人机侦察），其部署成本存疑。

- **物理可解释性缺乏直接验证**：虽然 SPPB 声称从 DINOv3 语义特征中检索到“发射率”“曝光最优性”“聚焦概率”等物理参数，但论文未提供这些检索结果的定量验证（如与真实物理测量值的相关性分析或可视化热图），物理量更多是概念性类比而非严格回归。

- **理论模型的简化假设**：式(1) 假设内在成分 Φ 在所有模态间共享且不变，但在实际场景中，不同传感器（如红外与可见光）的固有物理量（温度 vs 反射率）本质上并非同一实体，这种“共享内在”是一种近似；此外，变化成分 Ψ 与内在成分 Φ 的非正交性仅靠残差网络修正，缺乏更强的物理约束。
- **对比公平性细节欠缺**：论文未交代对比方法的训练协议（是否统一用官方权重、是否在同一硬件上重训练、超参数是否微调），以及是否所有评测脚本一致，这对“全面 SOTA”结论的可信度有一定影响。

## 9. 总结与个人评价

- **理论贡献**：本文的核心贡献不在于某一种融合网络结构，而在于将多模态融合重新定义为“物理量解耦 + 内在成分融合”的问题。借用 Retinex、辐射模型、散焦模型三者结构上的同构性，说明 MMIF 存在统一解，这一视角为后续研究提供了新的理论入口。
- **方法贡献**：SPPB 是“视觉基础模型用于底层物理量估计”的有益尝试。它把 DINOv3 强大的语义表征能力转化为空间变化置信图的预测依据，一定程度上缓解了底层视觉任务缺乏语义标注的难题；同时 LoRA 轻量适配避免了大规模微调，设计上兼顾了灵活性与资源开销。
- **工程贡献**：一个架构 + 两阶段训练流程打通三种异质融合任务，并在五个数据集上取得一致领先，工程实现的完整性与可复现性较好。
- **潜在局限与改进方向**：未来工作可从三方面推进：一是引入更轻量的语义主干（如蒸馏版 ViT）或在线量化/剪枝，使物理解耦框架适用于实时系统；二是用显式物理模型（如标定发射率图、光度立体法）直接监督 Ψ 的估计，增强可解释性；三是扩展消融与跨域评估，验证方法在多传感器（SAR-可见光、深度-RGB）下的泛化能力。
- **综合判断**：这是一篇思路新颖、理论支撑较强、实验覆盖较广的高质量工作，提出的“先解耦、后融合”范式有望成为多模态图像融合领域一个新的基准性参考。但若要被社区广泛采纳，仍需在效率透明性和物理验证严谨性上进一步补强。
