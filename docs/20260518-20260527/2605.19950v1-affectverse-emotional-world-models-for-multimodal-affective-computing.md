## 摘要
人类通过整合观察到的多模态线索以及对情感状态可能如何展开的预期来推断情感。然而，现有的多模态大语言模型（MLLMs）通常将情感识别视为对完整音视频文本输入的静态融合，忽略了情感动态。我们提出了AffectVerse，一个基于Qwen2.5-Omni的模型，配备了情感世界模块（EWM），这是一个无动作的表示级模块，用于短时域潜在情感预测。EWM包含三个子模块：1）跨模态时间想象，通过多步展开从过去的token预测未来的视频/音频表示；2）MAMA（模态感知多步注意力）信念聚合，将想象的token压缩成模态感知的信念token；3）信念注入，将这些信念token插入LLM以进行情感推理。AffectVerse将未来预测作为过去条件下的自监督信号：它并不替代对已观察历史的建模，也不要求在推理时使用未见信号，而是迫使当前信念状态编码能够预测后续情感变化的过渡线索。在九个基准测试中，AffectVerse相比其他模型至少提升2.57%，而控制消融实验表明，时间想象、跨模态展开和信念聚合带来了累加增益。这些结果表明，预测性信念状态建模是情感计算的一个实用替代方案。

## Abstract
Humans infer emotions by integrating observed multimodal cues with expectations about how affective states may unfold. Existing multimodal large language models (MLLMs), however, often treat emotion recognition as static fusion over complete audiovisual-text inputs, leaving affective dynamics implicit. We propose AffectVerse, a Qwen2.5-Omni-based model equipped with an Emotion World Module (EWM), an action-free representation-level module for short-horizon latent affective prediction. \rev{EWM contains three modules: 1) Cross-Modal Temporal Imagination predicts future video/audio representations from past tokens with multi-step rollout. 2) MAMA(Modality-Aware Multi-step Attention) Belief Aggregation compresses imagined tokens into modality-aware belief tokens. 3) Belief Injection inserts these belief tokens into the LLM for affective reasoning.} AffectVerse uses future prediction as a past-conditioned self-supervised signal: it does not replace modeling observed history or require unseen signals at inference, but forces the current belief state to encode transition cues that are predictive of subsequent affective change. Across nine benchmarks, AffectVerse improves at least 2.57\% over other models, while controlled ablations show additive gains from temporal imagination, cross-modal rollout, and belief aggregation. These results suggest predictive belief-state modeling is a practical alternative for affective computing.

- **现有问题**：当前多模态大语言模型（MLLMs）在情感识别中通常将完整的音、视频和文本输入视为静态快照，通过静态模式匹配或特征融合来判别情感，忽略了情感状态随时间演化、升级、恢复或跨模态冲突的动态特性。
- **研究动机**：人类情感推理不仅依赖于当前观察，还依赖于对情感如何展开的预期（预测性推理）。受情感科学中“情感是主动构建的预测过程”启发，作者提出应将情感识别建模为**预测性信念状态更新**，而非静态分类。
- **核心含义**：通过引入“情感世界模块”（EWM），让模型在观察到部分证据后预测短时域内的潜在情感走向，并将预测结果转化为信念状态注入大语言模型，从而实现动态、可校准的情感理解。

### 2.2 子模块详解

#### ① Cross-Modal Temporal Imagination（跨模态时间想象）
- **目的**：从过去的视频/音频 token 预测未来的潜在表示。
- **技术细节**：
  - 对每一模态的视频和音频隐藏状态进行**瓶颈下投影**（d=3584 → dw=512），起到信息瓶颈作用。
  - 在训练时按随机保持比 κ ~ Uniform[0.7, 1.0) 进行**时间分割**，将 token 分为过去部分和未来部分（未来部分作为自监督目标，梯度截断）。
  - 使用 **S=3 步 rollout**，每步使用 Ns=8 个可学习的未来查询 token，通过交叉注意力生成未来预测。
  - 每步预测（`Ş̂(s)`）与真实未来表示（经自适应池化匹配数量）计算 **MSE + 余弦距离**作为想象损失。
  - 引入**模态丢弃**（概率 0.15），训练模型在部分感官证据下依然能构建信念。
  - 跨模态上下文构建：预测视频时，同时使用自身过去（+自身标签）和音频过去（+跨模态标签）；音频同理。共享参数，仅用步嵌入区分时序。

#### ② MAMA Belief Aggregation（模态感知多步注意力信念聚合）
- **目的**：将多步、多模态的想象输出压缩成紧凑的信念 token。
- **技术细节**：
  - 将视频和音频的 multi-step 想象输出拼接成**记忆库**，加上类型嵌入（区分模态）。
  - 使用可学习的**信念查询**（动态数量：双模态 Nq=8，单模态 Nq=4）通过交叉注意力从记忆库中提取信息。
  - 加入**边界状态残差注入**：将分割边界处的最后视频/音频 token 的平均值通过可学习缩放 α 加到输出上。
  - 最终信念 token 经上投影回 LLM 隐藏维度。

#### ③ Belief Injection（信念注入）
- **目的**：将信念 token 插入 LLM 的 token 序列，使 LLM 在推理时能利用预测性信念。
- **技术细节**：
  - 将信念 token 分成两半，分别注入到两个位置：
    1. 音视频 token 与文本 token 之间；
    2. 文本 token 与答案区域之间。
  - 训练时根据 κ 截断部分音视频 token（部分观测正则化），但信念 token 的 attention mask 设为 1，标签设为 -100（不参与语言建模损失）。
  - 推理时 κ=1.0，保留所有观测 token，信念 token 作为辅助动态摘要。

### 2.3 训练目标
- **总损失**：`L_total = L_lm + λ_img * L_imagine`，其中 λ_img = 1.0。
- **L_lm**：标准自回归交叉熵损失（仅对助理响应部分计算）。
- **L_imagine**：所有 rollout 步骤和所有可用模态的想象损失的平均（MSE + 0.5×余弦距离）。

## 六、主要结论与发现

1. **性能提升**：在 A+V+T 全模态设置下，AffectVerse 平均达 77.34%，比 Qwen2.5-Omni（74.76%）和 AffectGPT（74.77%）提升至少 **2.57%**，在 9 个基准中的 8 个上排名第一。最大增益出现在 CMU-MOSEI（+5.06% over Omni）和 MER2024（+3.59%）。
2. **各组件贡献**：跨模态想象是最大的单点增益（+1.00%），MAMA、交错注入、残差注入均有累加效果（总 +3.07%）。
3. **鲁棒性**：在部分观测（κ 从 1.0 降至 0.1）或缺失模态时，AffectVerse 仍保持稳定，无剧烈下降，部分情况下中等截断甚至提升性能。
4. **最佳设计点**：S=3 步 rollout、Nb=4 基础信念 token、模态丢弃 p=0.15、λ_img=1.0 为最优平衡。
5. **信念机制有效**：MAMA 信念查询表现出模态感知的特化（有的整合双模态，有的专注于单一模态），预测性信念帮助模型在更多时间证据出现时修正错误判断（案例研究）。

## 七、优点

- **创新性强**：首次将世界模型式预测性学习引入多模态情感计算，且采用无动作（action-free）形式，适配情感推理场景。
- **设计精细**：
  - 跨模态上下文融合（自+他模态标签）优于纯自模态或纯他模态。
