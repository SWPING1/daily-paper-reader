## 摘要
自然场景中的情感行为识别需要从无约束人脸图像中联合预测连续的效价-唤醒度、分类面部表情以及多标签动作单元。我们针对第11届ABAW竞赛的s-Aff-Wild2（Aff-Wild2的静态帧选取版本）多任务学习赛道提出系统方案。该方法聚焦于编码器后适配：冻结的AffectNet监督骨干网络提供多分辨率特征，而任务特定的时间头与跨任务融合模块为每个目标选择有效信号。对于动作单元识别，我们采用低秩适配的MAE-Face，并通过每个单元专家路由而非直接顺序转移使用DISFA。通过消融实验对比骨干网络、时间模块、融合策略以及动作单元适配方案，确定了最终配置。该最终系统在官方验证集上取得P=1.7302，表明编码器后适配与任务级建模选择能够提供强大的多任务学习流程，而无需训练新的大规模人脸基础模型。

## Abstract
Affective behavior recognition in the wild requires joint prediction of continuous valence-arousal, categorical facial expression, and multi-label action units from unconstrained face images. We present our system for the Multi-Task Learning (MTL) track of the 11th Affective Behavior Analysis in-the-wild (ABAW) competition on s-Aff-Wild2, the static selected-frame version of Aff-Wild2. The method focuses on post-encoder adaptation: frozen AffectNet-supervised backbones provide multi-resolution features, while task-specific temporal heads and cross-task fusion modules select the useful signals for each target. For action-unit recognition, we adapt MAE-Face with Low-Rank Adaptation (LoRA) and use DISFA through per-unit expert routing rather than direct sequential transfer. Ablations over backbone, temporal, fusion, and AU-adaptation choices define the final configuration. The final system obtains P = 1.7302 on the official validation split, showing that post-encoder adaptation and task-wise modeling choices provide a strong MTL pipeline without training a new large-scale face foundation model.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：在无约束自然场景（in-the-wild）中，面部情感行为识别需要同时完成三个相关但异构的子任务：连续效价-唤醒度（VA）回归、8类面部表情（EXPR）分类、以及12个动作单元（AU）的多标签检测。现有方法往往需要训练大规模的面部基础模型，成本高昂且数据标注困难。
- **背景**：第11届ABAW竞赛的多任务学习（MTL）赛道基于s-Aff-Wild2数据集（约22.1万帧），要求单个模型输出三个任务的预测，评价指标P为三个任务指标的加权和（平均CCC、宏F1、平均F1）。该赛道面临部分标注、AU标签稀疏、类不平衡等挑战。
- **整体含义**：本文探索是否可以通过**冻结已有监督预训练编码器**，再通过编码器后的轻量级适配（任务头、时间建模、跨任务融合、参数高效微调）来构建高性能多任务流水线，而无需从头训练新的大规模模型。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：**编码器后适配**（post-encoder adaptation）。冻结两个AffectNet监督预训练的骨干（EfficientNet-B2和DDAMFN）提供多分辨率特征，分别用于不同任务；对于AU任务，则通过LoRA微调自监督MAE-Face作为专家编码器。在此基础上构建任务特定时间头和跨任务特征融合模块，并通过系统的消融实验选择最优组合。
- **关键技术细节**：
  - **冻结骨干与特征提取**：
    - EfficientNet-B2（ENET）：输入260×260，输出嵌入1408维 + 8个表情logits。
    - DDAMFN：输入112×112，输出512维嵌入 + 8个logits。
    - MAE-Face ViT-B（自监督）：输入224×224，输出1536维（类token+平均patch token串联）。该编码器在AU任务上通过LoRA微调。
  - **初始任务头**（基于冻结特征）：
    - VA：基于DDAMFN嵌入，使用两层MLP + tanh输出，损失为MSE+CCC。
    - EXPR：基于串联特征（DDAMFN嵌入+ENET嵌入+两者logits，共1936维），使用8类softmax，损失为带类别权重的交叉熵+标签平滑。
    - AU：基于ENET嵌入，12个独立sigmoid输出，损失为非对称损失(ASL) + 平滑F1损失（带碰撞防护）。
  - **时间模型**：
    - 按视频分组，帧序列划分窗口（长度L=48，可调）。
    - VA和EXPR分别使用GRU或双向GRU。VA拆分为独立的效价和唤醒度GRU头。AU不使用时序建模。
  - **跨任务特征融合**：
    - AU特征作为捐赠者馈入VA和EXPR头。例如EXPR头输入为[xei, F_au]；VA头中输入为[di, F_au, 对面情绪的时间状态]，实现效价-唤醒度交叉融合。
    - AU头保持独立（融合会损害其性能）。
  - **AU专家路由**：
    - 使用DISFA外部数据（75k帧，标注8个AU）进行LoRA微调初始化，再在Aff-Wild2上继续训练。但直接微调后的模型不如仅用Aff-Wild2的模型。因此采用**逐AU专家选择**（per-unit expert routing）：为每个AU列独立选择验证F1最高的候选模型（包括单独微调的、混合特征的等），保留其阈值，最终融合。
  - **后处理**：
    - 7帧移动平均平滑（S7）。
    - EXPR：加类别偏置b后argmax。
    - AU：对平滑后的sigmoid输出使用每AU阈值θ，二值化。
    - VA：裁剪到[-1,1]。
  - **集成**：对于VA用3种子平均；EXPR用Top-3候选平均；AU保留逐AU专家选择。

- **公式/算法流程**（文字）：
  - 总指标：P = M_VA + M_EXPR + M_AU，其中M_VA为平均CCC，M_EXPR为8类宏F1，M_AU为12 AU平均F1。
  - 每个任务选择验证性能最佳的候选模型f*_t = argmax M_t(f)。
  - LoRA更新：W' = W + (α/r)BA，r=16，α=32。
  - AU损失：L_AU = L_ASL + λ(t)*L_sF1，其中L_sF1为平滑F1代理损失，λ(t)在预热后斜坡上升，且若验证正例率>0.8或AU F1<0.42则禁用。

## 6. 主要结论与发现

- **最终性能**：在s-Aff-Wild2验证集上P=1.7302，其中VA平均CCC 0.6596，EXPR宏F1 0.5097，AU平均F1 0.5609。
- **关键发现**：
  1. 对于VA和EXPR任务，**编码器不是瓶颈**：冻结AffectNet监督特征已足够强，微调MAE-Face反而降低性能。努力应放在编码器之后（时间建模、融合）。
  2. **跨任务特征融合**主要提升EXPR（+0.0364），VA提升微小（+0.0025），AU保持独立最佳。
  3. **外部数据DISFA直接转移效果差**（域差异），但可通过逐AU专家路由利用其特征。
  4. **时间窗口长度**从32增至48提升融合后性能（+0.031）。
  5. **集成**（多种子+Top-3）带来适度提升（+0.013）。
  6. 水平翻转TTA有害（由于表情和AU不对称）。
