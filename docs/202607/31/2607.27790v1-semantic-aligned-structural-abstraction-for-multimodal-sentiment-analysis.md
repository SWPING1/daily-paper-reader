## 摘要
多模态情感分析（MSA）旨在通过整合自然语言与非语言模态来解释复杂的人类情感。非语言模态与自然语言具有结构同构性，因为二者都可以视为随时间演变的特征序列。这种同构性使得将非语言模态转换为类似文本的标记以进行统一语义推理成为可能。大语言模型（LLMs）设计用于理解和生成序列数据，因此可用于解释复杂的情感序列。然而，现有的基于LLM的方法主要捕获低层表面特征，无法建模由结构变化和上下文交互产生的情感语义。为解决这一局限性，我们提出了SentiLLM，一个统一框架，利用语义对齐的结构抽象将连续的原始信号蒸馏为紧凑、语义上有意义的标记。具体而言，我们引入了一种双流显著性-上下文校准机制，将非语言特征序列分解为焦点流和背景流。焦点流在文本先验的指导下捕获显著的情感转变（例如面部表情），而背景流则表征稳定的背景状态。通过将这些动态情感转变与背景状态进行校准，SentiLLM有效地将非语言模态投影到一个统一的语义空间中，使其对LLMs而言自然可理解。作为一个即插即用模块，SentiLLM仅用少量可训练参数即可显著提升判别性能。我们的方法在四个数据集（MOSI、MOSEI、CH-SIMS和CH-SIMS v2）上取得了优越的性能，证明了结构抽象范式在MSA中的有效性。我们的代码可在https://github.com/especiallyW/SentiLLM获取。

## Abstract
Multimodal Sentiment Analysis (MSA) aims to interpret complex human emotions by integrating natural language with non-verbal modalities. Non-verbal modalities share a structural isomorphism with natural language, as both can be viewed as feature sequences evolving over time. This isomorphism enables the transformation of non-verbal modalities into text-like tokens for unified semantic reasoning. Large Language Models (LLMs), designed to understand and generate sequential data, can thus be utilized to interpret complex affective sequences. However, existing LLM-based methods primarily capture low-level superficial features, failing to model affective semantics arising from structural variations and contextual interactions. To address this limitation, we propose \textbf{SentiLLM}, a unified framework that leverages \textit{Semantic-Aligned Structural Abstraction} to distill continuous raw signals into compact, semantically meaningful tokens. Specifically, we introduce a \textit{Dual-Stream Salience-Context Calibration Mechanism}, which disentangles non-verbal feature sequences into a focus stream and an ambient stream. The focus stream captures salient sentiment shifts (e.g., facial expressions) guided by textual priors, while the ambient stream characterizes stable background states. Through calibrating these dynamic sentiment shifts against background states, SentiLLM effectively projects non-verbal modalities into a unified semantic space, making them naturally understandable for LLMs. Serving as a plug-and-play module, SentiLLM significantly improves discriminative performance with only a small number of trainable parameters. Our method achieves superior performance on four datasets, MOSI, MOSEI, CH-SIMS, and CH-SIMS v2, demonstrating the effectiveness of the structural abstraction paradigm in MSA. Our code is available at: \href{https://github.com/especiallyW/SentiLLM}.

- **核心问题**：现有基于 LLM 的 MSA 方法（如 UniMSE、UniSA、MSE-Adapter）主要采用粗粒度的线性映射或简单的指令微调，仅能捕获低层表面特征（如面部纹理、声学频率），难以提取微妙的情感线索（如愤怒的颤抖、讽刺的语气）。这种**外观-语义错位**导致非语言特征无法与 LLM 语义空间对齐，限制了对情感语义的细粒度推理。
- **核心论点**：情感并非静态时间步的映射，而是**显著语义转变与上下文状态的结构统一体**。作者提出人类情感判断遵循"焦点-背景校准"机制：人首先关注显著情感转变（焦点），再通过上下文线索验证其可靠性（背景）。基于此，理想的情感标记需满足**结构性**（代表动态过程而非静态快照）和**校准性**（经上下文验证以确保语义稳定）。

## 2. 论文提出的方法论

### 2.1 核心思想

提出 **SentiLLM** 框架，基于**语义对齐结构抽象**，将连续的、未对齐的原始信号蒸馏为紧凑的、语义上有意义的标记（sentiment tokens），使其能够在 LLM 语义空间中直接参与跨模态推理。该框架仅需少量可训练参数，即可实现从原始信号到 LLM 可理解情感标记的结构化语义翻译。

### 2.2 总体架构

论文的 SentiLLM 架构包含四个核心组成部分：

1. **语义对齐结构抽象模块**：处理视觉与音频特征序列，包含两个子模块——上下文时序编码和双流显著-上下文校准。
2. **上下文时序编码（Contextual Temporal Encoding）**：原始特征 F_m 缺乏时序因果关系和上下文依赖，使用标准 Transformer Block（TF Block）建模长程时序依赖，并引入绝对位置编码（PE）保留时序先验，得到上下文感知特征 H_m。
3. **双流显著-上下文校准（Dual-Stream Salience-Context Calibration）**：包括软显著性解耦、双查询抽象和上下文校准三个环节。
4. **LLM 推理**：将文本特征与校准后的情感标记拼接，加 [CLS] 标记输入 LLM，提取 [CLS] 标记进行情感预测。

### 2.3 关键技术细节

**（1）软显著性解耦（Soft Salience Disentanglement）**

- 使用轻量级显著评分网络计算每个时间步的显著性概率 S_t：
  - S = σ(W₂ · GELU(W₁H_m + b₁) + b₂)
- 通过 soft mask 对特征进行加权解耦：
  - H_foc = H_m ⊙ S（焦点流，承载显著情感转变）
  - H_amb = H_m ⊙ (1 - S)（背景流，承载背景状态）
- 保留完整时间长度和位置信息，实现自适应信息分离，避免硬截断的信息丢失。

**（2）双查询抽象（Dual-Query Abstraction）**

- **焦点流（显式情感提取）**：使用预定义的文本锚（如"intense body language"、"rapid tone"）经 LLM 嵌入作为初始化查询向量 Q_foc，通过交叉注意力从焦点流检索动态情感模式，将音视频信号显式对齐到 LLM 语义空间。
- **背景流（隐式背景提取）**：使用随机初始化的可学习查询向量 Q_amb，通过交叉注意力自适应地总结全局背景状态，为验证焦点流可靠性提供上下文参考。

**（3）上下文校准（Context Calibration）**

- 基于"焦点-背景校准"假设，使用背景状态调制焦点情感：
  - 生成置信度门控系数 α = σ(Linear(E_amb))
  - 调制后的情感 E_mod = α · E_foc
  - 最终情感标记 Z_m = FFN(E_foc + E_mod)
- 通过前馈网络将结果映射至 LLM 潜在空间，确保情感标记的语义稳定性和一致性。

**（4）统一 LLM 推理**

- 输入序列构建：H_in = Concat(Z_t, Z_v, Z_a, [CLS])，利用 LLM 的序列建模能力进行跨模态交互，提取 [CLS] 标记获得预测。

**（5）优化目标**

- 任务损失：回归任务采用 Mean Absolute Error（MAE）
- 稀疏损失：约束平均激活率接近预设的稀疏率 k，防止模型塌缩到平凡解
- 总目标：L_total = L_cls + λL_sp

- **SentiLLM 显著超越传统融合方法和现有 LLM-based 方法**：在 MOSI 上 Acc-2 达 89.02%（超越最强对手 MSE-ChatGLM-6B 0.97 个百分点），在 MOSEI 上实现一致的性能提升。

- **方法具备良好的可扩展性**：随 LLM 规模增大，MAE 呈严格单调递减趋势。
- **发现长尾分布限制**：极端情感类别（如 HN、HP、中文 NT 类）因样本稀缺而识别性能最差。

## 7. 优点

- **理论创新性强**：将非语言模态与自然语言的结构同构性作为理论出发点，提出"焦点-背景校准"的认知假设，并据此设计了双流机制，赋予模型解释性理论根基。
- **参数高效**：仅 0.32% 的可训练参数（约 5M），即可在多个基准上取得最优性能，堪称轻量级即插即用模块。
- **方法简洁有效**：采用软显著性解耦而非硬截断，保留完整时序信息，通过软掩码实现可微分的自适信息分离。
- **语义对齐巧妙**：利用文本锚查询向量显式引导注意力捕获细粒度情感线索，大幅缩小音视频与 LLM 语义空间的鸿沟。
- **实验全面严谨**：覆盖 4 个数据集、多种 LLM、全维度消融与丰富的可视化分析（t-SNE、LDA、混淆矩阵），实验设计系统完整，代码已开源。
- **跨语言通用性**：在中文和英文数据集上均取得优异表现，展示了结构抽象范式的语言无关性。

## 8. 不足与局限

- **可解释性不足**：依赖 LLM 推理进行分类，但分类标签本身无法完整揭示内部的决策逻辑，缺乏生成式解释来提升透明度和可解释性。
- **缺失模态场景未处理**：方法假设所有模态齐备，未考虑实际应用中数据损坏导致的模态缺失情况，在缺失模态场景下模型的鲁棒性缺乏验证。
- **跨语言对齐存在瓶颈**：在 CH-SIMS v2 中文数据集上，对英文本位模型（如 Gemma）存在精度轻度下降，性能未能超越 GPT 原生中文模型（MSE-ChatGLM-6B），跨语言对齐尚需加强。
- **长尾分布识别困难**：混淆矩阵显示极端情感样本（Highly Negative / Highly Positive）以及中文中立类因样本稀缺识别率较低，长尾多模态学习问题亟待解决。
