## 摘要
音视频模型通过利用互补线索提升第一视角动作识别，但通常假设推理时两个流均可用。现有缺失模态方法处理的是经过裁剪的单事件片段，其中某个流要么完全存在要么完全缺失；而真实传感器会在长时、未裁剪的观测过程中失效并恢复。我们将第一视角模态缺失重新定义为未裁剪、多事件观测中时间局部化的传感器中断，并将整段片段缺失视为其极限情况。我们提出 MacJEPA，一种对缺失模态鲁棒的掩码上下文查询 JEPA，其根据在音视频上下文上提供的区间查询来识别视觉动作和声学事件。窗口局部模态丢弃在训练期间模拟这些传感器中断。MacJEPA 进一步将 JEPA 中的掩码从自监督前置任务重新用作有监督鲁棒性目标，对齐多模态内容 token 与任务条件查询的掩码和干净潜在表示。所有目标与识别在单阶段中联合优化，无需测试时自适应。在 Epic-Kitchens-100 和 Epic-Sounds 上，单个检查点在完整输入下仍具竞争力，并且在移除主导流或辅助流时始终优于已发表的缺失模态基线。因此，MacJEPA 在单个处理未裁剪多事件视频的模型中统一了强大的完整输入识别与时序缺失模态鲁棒性。

## Abstract
Audio-visual models improve egocentric action recognition by exploiting complementary cues, yet typically assume that both streams remain available at inference. Existing missing-modality methods operate on trimmed, single-event clips in which a stream is entirely present or absent, whereas real sensors fail and recover within long, untrimmed observations. We redefine egocentric modality missingness as temporally localized sensor outages within untrimmed, multi-event observations, with whole-clip absence as the limiting case. We introduce \textbf{MacJEPA}, a missing-modality-robust \textbf{Ma}sked-\textbf{c}ontext query \textbf{JEPA} that recognizes visual actions and acoustic events from supplied interval queries over audio-visual context. Window-local modality dropout simulates these sensor outages during training. MacJEPA further repurposes masking in JEPA from a self-supervised pretext into a supervised robustness objective, aligning masked and clean latent representations of both multimodal content tokens and the task-conditioned queries. All objectives are optimized jointly with recognition in a single stage, requiring no test-time adaptation. Across Epic-Kitchens-100 and Epic-Sounds, a single checkpoint remains competitive under complete input and consistently surpasses published missing-modality baselines when either the dominant or auxiliary stream is removed. MacJEPA thus unifies strong full-input recognition with temporal missing-modality robustness in a single model operating on untrimmed multi-event videos.

## 1. 核心问题与研究动机

- **背景**：第一视角（egocentric）视频中，视觉信号本身脆弱（头部运动、遮挡、手部/物体出画），而声音在视觉证据缺失时仍可提供互补线索，因此音视频模型成为该领域 SOTA。
- **现实矛盾**：这些模型普遍假设推理时双流始终可用。但在可穿戴设备部署中，麦克风可能因隐私被静音、传感器为省电而占空比运行、硬件可能故障，导致某一模态失效。这种退化往往并不"优雅"——丢失一个流后，多模态模型甚至可能低于仅在幸存流上训练的单模态模型。
- **现有方法的局限**：已有缺失模态方法（MMG-Ego4D、MMT、KARMMA、MIDL 等）都作用于**以单一事件为中心的已裁剪片段**，把每个流视为"整段全有或全无"，即缺失性是**跨片段**测量的，隐含地将传感器中断与动作边界对齐。而真实部署中系统需处理背景、部分动作、多个时间上重叠的视觉与声学事件。
- **重新定义问题**：论文将第一视角模态缺失重新定义为**未裁剪、多事件观测中的时间局部化传感器中断**（sensor outages），整段片段缺失只是其极限情况。核心问题从"哪个模态在片段中缺失"变为"**何时缺失、哪些事件因此失去可区分证据**"。
- **论文引言给出的典型场景**（19.2 秒厨房片段）：隐私静音使 Open 事件失去音频、短暂相机故障裁掉 Turn On Tap 的视觉证据；在重叠的 Pour Water / Turn Off Tap / Water 事件期间，音频在 6.4–8.5s 丢失、视频在 8.5–12.8s 丢失、音频又在 12.8–14.9s 丢失，反复改变可支撑识别的流。这种局部中断使多个重叠事件不同程度地失去证据。

## 2. 方法论

### 2.1 核心思想

- 提出 **MacJEPA**（Missing-modality-robust **Ma**sked-**c**ontext query **JEPA**）：在未裁剪音视频上下文上，由**给定的区间查询（interval query）** 识别视觉动作与声学事件。
- 三个关键改造：
  1. 用**窗口局部模态丢弃**模拟局部传感器中断；
  2. 将 JEPA 的掩码从"自监督前置任务"改造为**有监督鲁棒性目标**（对齐掩码与干净的潜表示）；
  3. 将对齐范围从内容 token 扩展到**任务条件查询**，且与识别任务**单阶段联合优化**，无需测试时自适应。

### 2.2 问题设定与查询序列构建

- 对每个模态 m ∈ {v, a}，用冻结的单模态编码器 b_m 在共享时间网格（步长 Δ，感受野 ω = 2Δ）上产生时序特征。一个观测 X_m 为 T 行的连续切片，跨度 S = TΔ。
- 候选观测以一行间隔平铺整段视频，与标注无关，可能起止于事件内部、含大量背景或无标注动作；当标注与观测重叠 ≥ δ = 0.2 s 或完全包含时被指派。
- 时间编码：共享 TimeMLP φ: R² → R^{d_t} 将连续区间映射为时间表示，为两个模态提供统一"时钟"。内容行 j 的时间为 t_j = [jΔ, jΔ+ω]/S，查询区间裁剪归一化得 t_q ∈ [0,1]²。
- Token 构造：
  - 内容 token：u^m_{k,f} = [g_m(x^m_{kw+f}) ‖ φ(t_{kw+f})] + e_m
  - 查询 token：u_q = [ch(q) ‖ φ(t_q)] + e_{m(q)}
  - 其中 g_m 为模态 stem（含 feature dropout，投影到公共内容空间 d_c），e_m 为模态嵌入，ch(q) 为可学习查询种子。
- 序列 = 2T 个多模态内容 token + 各标注对应的 verb / noun / action 查询（Epic-Kitchens）与 sound 查询（Epic-Sounds）。
- **注意力掩码**：内容 token 只能关注内容；每个查询可关注全部内容与自身，但不关注其他查询。这保证编码上下文与查询集合无关、每个预测相互独立。

### 2.3 窗口局部模态丢弃（Window-Local Modality Dropout）

- 将 T 行划分为 K = T/w 个不重叠窗口（每个跨度 τ = wΔ），用二值掩码 M ∈ {0,1}^{K×|M|} 指定每个窗口哪个模态缺失。
- 每个窗口独立采样三种状态，概率为 1−π（完整）、π/2（丢视频）、π/2（丢音频）；**排除双流同时丢失**，保证每个时刻至少保留一个传感器证据。
- 掩码方式为**替换而非删除**：缺失特征被可学习的缺失嵌入 e^m_∅ 替代，但保留时间编码与模态标签，构成"**有类型、有时间戳的缺失**"（typed, timed absence），使编码器知道"哪个流在何时不可用"。
- 窗口化使模拟中断具有真实时长：相邻行 50% 重叠，仅掩一行会被邻居补偿；当 w > 2 时 τ > ω，单特征无法从重叠恢复。
- 组合空间从片段级 dropout 的 3 种状态扩展为 **3^K 种窗口配置**（每轮 epoch 重采样）；整段缺失（所有窗口同一模态）仍落在支撑集内。

### 2.4 内容 JEPA 与查询 JEPA

- 在线编码器 f_θ 处理掩码序列，EMA 教师 f_θ̄ 处理干净序列（同一观测与查询，仅在线分支含模拟中断），教师不接收梯度：θ̄ ← αθ̄ + (1−α)θ，动量从 0.996 线性升至 0.9999。
- 共享的**逐 token 预测器** h_ψ（d → 384 → d 瓶颈 MLP，**无注意力**、不接收额外掩码描述），将在线状态映射向干净目标。刻意限制预测器容量与条件，避免其"自行逆转破坏"，从而迫使鲁棒性产生在保留下来用于推理的在线编码器中。
- 损失（对 stop-gradient、参数自由 LayerNorm 后的教师目标做 L1 回归，d₁(u,v)=‖u−v‖₁/d）：
  - **内容损失 ℓ_ctx**：覆盖全部 n = 2T 个内容状态（而非仅被掩位置），因为全局注意力会把破坏传播到已观测 token；
  - **查询损失 ℓ_qry**：在 corrupted 与 clean 上下文下对齐同一任务、同一区间的查询表示；
  - L_JEPA = ℓ_ctx + ℓ_qry，两项分别归一化，权重相等。
- **关键分析**：内容 token 不能关注查询，故 ∂ℓ_ctx/∂ch = 0——内容损失无法直接正则化分类器读取的查询种子；查询 JEPA 恰好补上这条梯度路径，直接把掩码-干净一致性施加在预测表示上。

### 2.5 总目标

- 分类损失：各头对有效查询做标签平滑交叉熵（ε = 0.1），L_CE 汇总 verb / noun / action / sound（sound 权重 λ_A = 0.1，action 头有 ramp）。
- 动作头采用**组合式分类器**：S_c(z) = a_{v(c)}(z) + b_{n(c)}(z) + I_c（3,806 类，I_c 初始化为 0 的可学习 verb–noun 兼容残差）。
- 附加 **VICReg**（方差 + 协方差项，仅施加于被观测的内容状态，排除替换 token）作为表示坍缩防护。
- 总损失：L = w_ce L_CE + w_jepa L_JEPA + w_vic L_VIC，所有目标从第一步起联合优化，系数在前 5 个 epoch 内 ramp 到终值。教师与预测器在训练后丢弃。

    - 作者主动承认协议不完全对齐：**TIM 匹配其观测协议，MMT/MIDL 匹配其观测级缺失协议，没有先验方法同时匹配两者**；MMT 行报告的是其模态完整 MBT 基线；
    - 单模态参考由作者自行训练，用于判断"鲁棒多模态推理是否仍优于单模态"。
  - **潜在公平性顾虑**：与 MMT/MIDL 的比较采用观测级缺失协议，而 MacJEPA 本身在未裁剪多事件观测上评估、平均每次前向含 8.59 个标注，任务难度与裁剪单事件片段不同；作者虽指出这一点，但未能做到严格同协议同设置。
